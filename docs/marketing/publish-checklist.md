# ZARIGANI 公開の準備(チェックリストと、紹介ページの下書き)

> 状態: 下書き(開発者の確認待ち)。ゲーム名は **ZARIGANI**(開発者が決定)。
> 公開(パブリッシュ)・設定の変更は、開発者がStudioで行う(Claude は、この環境から、Studioを操作できない)。

## 1. 公開の前にやること(Studio)
1. Studioで遊んで、エラー(「出力」の赤い文字)が出ないことを確かめる。
2. 稲刈り機・農家さんが、動くことを確かめる(時間を縮めて確認してよい。確認後に、`Config.luau` の `RoundSeconds` と `GrowthStageSeconds` を、元の値(300、{75, 170})に戻す)。
3. 上のメニューの「ファイル」→「Robloxに公開」で、新しいゲームとして、公開する。名前は **ZARIGANI**。
4. 「ゲーム設定」(Game Settings)を開いて、次を設定する。
   - **基本情報**: 名前=ZARIGANI、説明=下の下書き、ジャンル=サバイバル(またはアクション)、デバイス=パソコン・スマホ・タブレット(コンソールは、あとで)。
   - **最大プレイヤー数**: **1**(決定002。最初は一人用)。
   - **セキュリティ**: 「Studio で API サービスへのアクセスを有効にする」を ON(ベスト記録の保存を、Studioで確かめるため)。「サードパーティの販売を許可」は、OFF のまま。
   - **収益化**: 最初は、何もしない(課金なし)。
   - **プライバシー**: 最初は「非公開」で、友だちに遊んでもらい、問題がないことを確かめてから、「公開」にする。
5. **年齢のめやす(アンケート)**: ロブロックスの質問に、正直に答える。このゲームは、暴力・怖い表現が少ない(ザリガニが、農家さん・稲刈り機から逃げる。血・倒れる表現はない)。
6. 公開前に、`assets/CREDITS.md` の台帳に、使った素材(音など)を、すべて記録したか確かめる。外部の素材を、使っていなければ「なし」。

## 2. 紹介ページの下書き
### ゲーム名
**ZARIGANI**

### 説明文(下書き)
> 日本の田んぼで、ザリガニになって生き延びよう!
> 農家さんに見つかるな。潜って隠れても、近づきすぎると、つかまる。
> 稲が育って、稲刈りの日が来るまで、5分間、逃げきれ。ただし、終盤には、稲刈り機が動き出す。
> 田んぼのあちこちにある、橙色の餌を食べて、高い点数をねらおう。ベスト記録は、保存される。
> (一人用。スマホでも、パソコンでも遊べる)

### タグ・ジャンル(案)
サバイバル、逃げる、ザリガニ、田んぼ、日本、かわいい

### アイコン・サムネイル
- アイコン(正方形): 赤いザリガニの、大きなはさみと目が、よく見える絵。背景は、黄金色の稲。文字は、入れない(または、短く「ZARIGANI」)。
- サムネイル(横長): 黄金色の夕焼けの田んぼで、ザリガニが、巨大な農家さんから逃げる場面。稲刈り機が、遠くに見える。
- 作り方: Studioでゲームを動かして、画面を撮る(スクリーンショット)。夕焼けの終盤の画面が、いちばん映える。
- **画像は、自分で撮ったスクリーンショットか、自分で作ったものだけを使う**(外部の画像は、使わない)。

## 3. 公開後にやること
1. 友だち5〜10人に、遊んでもらう(`docs/playtest/` に、迷った場所・感想・継続率を、記録する)。
2. 宣伝の計画(`docs/marketing/launch-plan.md`)に沿って、縦動画を投稿する(`docs/marketing/video-scripts/` に、台本を置く)。
3. 遊ばれ方を見て、`Config.luau` の数字(農家さんの強さ、稲刈り機の速さ、餌の数など)を調整する。
