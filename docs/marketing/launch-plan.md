# 公開と宣伝の計画(チェックリスト)

方針: 「30秒で1回のごほうびがあるループ」を、縦動画で映える一瞬に仕立て、イベントで何度も再浮上させる。
(トレンドの数字は2026年10月時点の第三者の集計。変わるので、公開前に見直す)

## 第0週:準備
- [ ] 年齢確認を済ませる
- [ ] Roblox Studioを入れる
- [ ] 公式チュートリアルでLuauの基礎を学ぶ
- [ ] RoWatcherなどで、同ジャンルの人気作と投稿を観察する
- [ ] 空いているテーマを探す

## 第1〜2週:設計
- [ ] docs/game-concept.md を埋める
- [ ] ゲーム名を決める(探されそうな言葉を入れる)
- [ ] アイコン案を3つ作る

## 第2〜5週:制作とテスト
- [ ] 最小の版(核のループだけ)を作る
- [ ] 友人5〜10人に遊んでもらう
- [ ] 「初日に戻ってくる人の割合」を見る。低ければ作り直す

## 第5〜6週:公開前
- [ ] サムネ、スクリーンショット、15秒の予告動画
- [ ] 紹介文と年齢の目安の設定
- [ ] 縦動画を3本、先に撮っておく
- [ ] 小さめのゲーム系クリエイター5〜10人に、無料で試してもらうよう連絡する
- [ ] Discordサーバーを作る

## 第6週:公開
- [ ] 縦動画を毎日1本投稿する(TikTok、YouTubeショート)
- [ ] スポンサー広告を少額で3日試す(対象者・期間・1日の予算を選べる)
- [ ] 継続率が高ければ増やし、低ければ止める

## 第7〜12週:運用
- [ ] 週1回の更新と、更新ごとの予告動画
- [ ] 12月のクリスマス・年末年始イベントを、11月中に作り始める
- [ ] 反応が良かった動画の型を量産する
- [ ] ゲームパスを数個から始める(初日の体験を壊さない範囲で)
- [ ] 稼いだロバックスが貯まったら、DevExでの換金を考える(最低3万ロバックス、Premium会員が条件)

## 注意
- 流行作品の多くは短命。1本に全部を賭けず、小さく作って検証する。
- プレイヤーの大半は子ども。課金の誘導は、やりすぎない。
