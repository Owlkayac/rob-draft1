# 天敵の「ランダムな動き」の説明書

初心者向けの説明です。仕様書 014 のサーバー側(農家さんと稲刈り機のランダム性、気づく演出)に対応します。
巨人の歩きや足音の揺れなど、クライアント(画面)側の演出は、別に作ります。

## 用語

- **乱数(ランダム)**: 毎回ちがう数字を出す仕組み。ここでは Roblox の `Random` を使う。
- **シード(種)**: 乱数の出し方を決める最初の数字。同じシードなら、同じ順番で同じ数字が出る。
- **確率**: 0〜1 の数字。0.4 なら「10回に4回くらい」。
- **ゆらぎ**: 数字を、元の数字の前後(±)でゆらすこと。0.12 なら ±12%(0.88〜1.12倍)。
- **Attribute(属性)**: モデルにつけられる「名前つきのメモ」。サーバーがつけると、クライアントも読める。

## 1. ランダムの仕組み

- 天敵1体ごとに、自分だけの乱数を1つ持っています(`ctx.Random`)。農家さんと稲刈り機で、ランダムが混ざりません。
- 乱数は、天敵が作られるときに作られます。
  - `Config.EnemyRandomSeed = 0`(いまの設定): `Random.new()`。毎回ちがう動き。
  - `Config.EnemyRandomSeed` を 0 以外(例: 12345)にすると、その数字で固定。毎回、同じ順番でランダムが出るので、「あの動きがおかしい」を再現しやすい。(プレイヤーの動きや時間で結果が変わるので、完全に同じにはならないこともあります。)
- ランダムの道具は `Enemy/EnemyRandom.luau` にまとまっています。秒数は、0 にならないように、0.001 秒より小さくなりません。

## 2. 農家さんの動きの流れ

```
見回り(Patrol) --見つけた--> 気づく(Notice) --まだ見える--> 追跡(Chase)
     ^                          |                              |
     |                     見えなくなった                    見失った
     |                          v                              |
     +------ 時間が来た ---- 探す(Search) <---潜られた----------+
```

| 行動 | 頭の上 | ランダムなところ |
|---|---|---|
| 見回り | なし | 行き先、立ち止まる、きょろきょろ、歩く速さ、「勘」 |
| 気づく | 赤い「!」 | 立ち止まる時間(0.4〜0.9秒)。相手のほうを向く |
| 追跡 | 赤い「!」 | ダッシュ、つまずき、見失うまでの時間 |
| 探す | 黄色い「?」 | 探す時間、歩き回る場所と数 |

行動が変わるたびに、モデルの Attribute `EnemyState`(`Patrol` / `Notice` / `Chase` / `Search`)も変わります。

### 公平さ(ここは「運だけ」で負けないための決まり)
- 出現(作られたとき・「もう一度」)から 3 秒は、見回り・探すでは、プレイヤーを見つけません。
- 見つけても、最低 0.4 秒は走りません。
- 追跡の速さは、ザリガニの歩く速さの 1.05 倍(16.8)を超えません。ダッシュ中でも同じです。

## 3. Config の調整表

すべて `src/ReplicatedStorage/Shared/Config.luau` にあります。変えたら保存して、Studio で再生し直します。
「時間」「間隔」は 0 にしないでください。Min は Max 以下にしてください。

| 名前 | いまの値 | 意味 | 大きくすると | 小さくすると |
|---|---|---|---|---|
| `EnemyRandomSeed` | 0 | 乱数の種(0 = 毎回ちがう) | (0以外で固定) | |
| `FarmerRoamPointChance` | 0.5 | 行き先を「ランダムな点」にする確率 | 動きが読みにくい | 見回り地点を回る割合が増える |
| `FarmerRoamWallMargin` | 15 | ランダムな点を、壁からはなす距離 | 壁ぎわに行かない | 壁ぎわにも行く |
| `FarmerPauseChance` | 0.4 | 着いたとき立ち止まる確率 | よく止まる(隙が増える) | あまり止まらない |
| `FarmerPauseSecondsMin` / `Max` | 1.0 / 3.0 | 立ち止まる時間(秒) | 長く止まる | すぐ歩き出す |
| `FarmerWalkSpeedJitter` | 0.12 | 見回りの速さのゆらぎ | 速さのばらつきが大きい | 一定の速さ |
| `FarmerPatrolTargetTimeoutSeconds` | 20 | 見回りの行き先に着かないとき、あきらめて選び直すまでの時間(秒。保険) | 長く粘る | すぐ選び直す |
| `FarmerLookAroundMaxDeg` | 100 | きょろきょろする角度(度) | 大きく向きを変える | あまり変えない |
| `FarmerPauseTurnDegPerSecond` | 60 | きょろきょろの向きを変える速さ | 素早く向く | ゆっくり向く |
| `FarmerHunchIntervalMin` / `Max` | 8 / 14 | 「勘」を働かせる間隔(秒) | 勘が働く回数が減る | 勘が働く回数が増える |
| `FarmerHunchChance` | 0.5 | 勘でこちらへ向かう確率 | よくこちらへ来る(難しい) | 来にくい |
| `FarmerHunchErrorRadius` | 22 | 勘のずれの大きさ | 場所がぼんやりする | 正確にこちらへ来る(難しい) |
| `FarmerNoticeSecondsMin` / `Max` | 0.4 / 0.9 | 気づいて立ち止まる時間(秒) | 逃げる猶予が増える(簡単) | 猶予が減る(難しい) |
| `FarmerNoticeTurnDegPerSecond` | 360 | 気づいたとき相手を向く速さ | 素早く向く | ゆっくり向く |
| `FarmerBurstIntervalMin` / `Max` | 4 / 9 | ダッシュの間隔(秒) | ダッシュが減る | ダッシュが増える(難しい) |
| `FarmerBurstSeconds` | 1.0 | ダッシュの長さ(秒) | 長く速い(難しい) | 短い |
| `FarmerBurstMultiplier` | 1.12 | ダッシュ中の速さの倍率 | 速い(ただし上限まで) | 遅い |
| `FarmerStumbleIntervalMin` / `Max` | 6 / 14 | つまずく間隔(秒) | つまずきが減る(難しい) | つまずきが増える(簡単) |
| `FarmerStumbleSeconds` | 0.35 | つまずいて止まる時間(秒) | 長く止まる(簡単) | 短い |
| `FarmerChaseMaxSpeedRatio` | 1.05 | 追跡の速さの上限(ザリガニの何倍か) | 追いつかれやすい(難しい) | 逃げやすい |
| `FarmerLoseSightSecondsMin` / `Max` | 3 / 6 | 見失うまでの時間(秒) | しつこく追う(難しい) | すぐあきらめる |
| `FarmerSearchSecondsMin` / `Max` | 2 / 5 | 探す時間(秒) | 長く探す(難しい) | すぐ戻る |
| `FarmerSearchRoamRadius` | 18 | 探すとき歩き回る範囲(半径) | 広く探す | せまく探す |
| `FarmerSearchRoamSpotsMin` / `Max` | 1 / 2 | 歩き回る場所の数 | | |
| `FarmerStartGraceSeconds` | 3 | 出現直後に見つけない時間(秒) | 安全な時間が長い(簡単) | すぐ見つかる |
| `HarvesterSpeedJitter` | 0.08 | 稲刈り機の、線ごとの速さのゆらぎ | ばらつく | 一定 |

頭の上の表示(`FarmerSignSize`、`FarmerSignGap`、`FarmerSignMaxDistance`、`FarmerSignAlertText`、`FarmerSignAlertColor`、`FarmerSignSearchText`、`FarmerSignSearchColor`、`FarmerSignStrokeColor`)も、Config にあります。大きさ・高さは、農家さんの大きさ(`FarmerScale`)倍で使われます。

### 稲刈り機のゆらぎを大きくするとき(注意)
稲刈り機の速さを線ごとにゆらすと、いちばん遅い場合に、ラウンドの時間(300秒)に収まらなくなることがあります。
- 経路の長さ ÷ (速さ × (1 - ゆらぎ)) + 入るまでの 3 秒 + 出穂の始まり(165秒) < 300 秒
- いま: 1510 ÷ (13 × 0.92) ≒ 126.3 秒。165 + 3 + 126.3 + 最大1.2秒(段階更新の1秒刻みと、判断の間隔) ≒ 295.5 秒。300 秒より少し余裕があります。
- ゆらぎを 0.08 より大きくするときは、`GrowthStageSeconds` の2つめ(出穂の始まり)を小さくしてください。

## 4. 稲刈り機の入る側(西か東)

- 稲刈り機が出番になるたび、コインを投げるように、西か東をランダムに決めます。
- 東から入るときは、経路の点の左右を反転します(x を -x にする)。線の数も、順番も、長さも同じ。刃やモデルの向きは、進む向きに合わせて自動で合います。

## 5. Studio でランダムを確かめるコツ

- `EnemyRandomSeed` を 12345 などにして、何回か再生し直すと、似た動きになるか見られます。
- `EnemyRandomSeed` を固定すると、天敵を作るたびに、同じ乱数列になります。稲刈り機の西・東も、毎ラウンド同じ側になります(デバッグ用)。
- 確かめ終わったら、0 に戻してください(毎回ちがう動きに戻ります)。
- 「出力」に、エラー(赤い文字)が出ていないことを確かめてください。
