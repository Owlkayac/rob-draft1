# 決定 011: 効果音・環境音(仕組みだけ作る。IDは空)

- 日付: 2026-11-03
- 決めた人: 開発者(「全て番号順に実装」という依頼のうちの1つ。決定007の「次の質感の候補」4番)。仕様書は `docs/specs/011-sound.md`。

## 依頼
環境音・効果音を、あとから ID を入れるだけで足せるようにする。

## 決めたこと
- **仕組みだけ作る。音のID(素材の番号)は、すべて空のまま**にする。選んで入れるのは、開発者。
- 空・形が正しくない ID の音は、作らない・鳴らさない。空ならエラーも警告も出さない。

## 理由
- CLAUDE.md のルール6(外部の音・画像・モデルのIDは、勝手に使わない)。
- この環境からは、Roblox の音の素材の一覧を調べられず、存在するIDを確かめられない。勝手にIDを入れると、鳴らない音や、使ってはいけない音になる恐れがある。

## Claudeが選んだ案(あとで変えられる)
- **IDの形の検査**: `rbxassetid://` のあとが数字だけ、のときだけ受けつける(`SoundUtil.IsValidId`)。外部のURLなどは、警告を1回だけ出して無視する。
- **空なら鳴らさない**: Sound を作らない。再生の関数は、何もしない。
- **Caught・Clear は、状態が変わったときだけ**: RoundState は毎秒来るので、前と同じ状態の通知では、くり返さない。Playing に戻れば、また鳴らせる。
- **環境音**: Caught・Cleared では止めずに、`SoundAmbientDuckVolume` まで、なめらかに小さくする。Playing に戻ると元の音量へ。
- **Splash は 2D**: 仕様書の表は「ザリガニの位置(3D)」だが、聞くのは自分のキャラクターの音だけなので、SoundService の下の Sound で鳴らす(位置による違いがない)。
- **稲刈り機のエンジン音**: サーバーが胴体の中に作り(3D・距離で小さくなる)、Sweep が粒子と同じ形で、動いている間だけ再生する。
- **SoundController は、RoundState を自分でつなぐ**(ほかの部品とは独立)。ID がすべて空なら、何もせず終わる。

## 見直す時期
- 音を選んで入れたあと、うるさい・小さいと感じたとき(`SoundVolumes`、距離)。
- 仕様書 012 を実装するとき(`SoundController.PlayEat()` をつなぐ)。

## レビュー後の調整
- **Splash は、`Hidden` の値が実際に変わったときだけ**鳴らす。直前の値を覚えておき、キャラクターが生まれ直したら、覚え直す(このときは鳴らさない)。同じ値の通知や、生まれ直しの最初の値では鳴らない。
- **待ち時間は専用の設定**: `RoundState`・`ScoreState` を待つ時間は、`Config.LightEffectWaitSeconds` の流用をやめて、`Config.SoundWaitSeconds`(10)にした。
- **仕様書の Splash の説明を、実装に合わせた**: 「ザリガニの位置(3D)」から「全体(2D。自分の端末で、自分のザリガニの音を鳴らすため)」へ。`docs/specs/011-sound.md` と `docs/design/sound.md` を直した。
