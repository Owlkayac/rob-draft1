# 決定 009: 粒子の演出(刈りくず、土ぼこり、水しぶき)

- 日付: 2026-11-03
- 決めた人: 開発者(「全て番号順に実装」という依頼のうちの1つ。決定007の「次の質感の候補」2番)。仕様書は `docs/specs/009-particles.md`。

## 依頼
稲を刈った感じ、機械が動く感じ、ザリガニが水に潜る感じを、粒子(ParticleEmitter)で強める。

## 決めたこと
- Roblox に最初から入っている ParticleEmitter だけを使う。外部の画像・音・モデルは使わない。
- 粒子は各自の端末で動くので、サーバーの負担は小さい。数(Rate)は控えめにする。
- 数字は `Config.luau`(`HarvesterChaff...`、`HarvesterDust...`、`Splash...`)にまとめる。

## Claudeが選んだ案(あとで変えられる)
- **発生源は3つだけ**: 稲刈り機の刃(刈りくず)、稲刈り機の後ろ(土ぼこり)、ザリガニの胴体(水しぶき)。稲1本ずつからは出さない。
- **土ぼこりの発生源**: 後ろの車輪のあたりに、見えない薄い箱(`DustSource`)を置いて、そこにつけた。車輪は円柱で向きが分かりにくく、左右2つに分けたくないため。箱の底は床の高さで、モデルの大きさの計算(足元の高さ)は変わらない。
- **Texture は設定しない**: Roblox の既定のまま。素材台帳(assets/CREDITS.md)に1行記録した。
- **`Enabled` を切り替える**: サーバーで `Emit()` を呼んでも他の端末には見えない。粒子は最初から `Enabled=false` で作り、必要なときだけ true にする。
- **稲刈り機**: 実際に進んでいる間だけ true。入るのを待つ間、終了、Exit、消える前は false。状態が変わったときだけ書く。
- **水しぶき**: 潜る・浮上のとき true にして、`SplashBurstSeconds`(0.25秒)後に false。古いタイマーは番号(`SplashToken`)で無効にする。やり直し・生まれ直し・死亡では、番号を進めて false にする。
- 潜っている間の泡(仕様書の「任意」)は作らない。

## 見直す時期
- 重いと感じたら: 各 `Rate` を下げる。
- 見た目が合わないとき: 色・大きさ・広がり(`docs/design/particles.md`)。
- 泡、足跡などは、まだ作らない。

## レビュー後の調整(2026-11-03)
5. **刈りくず**: すぐ床の下へ落ちていたので、前と上に飛ぶようにした。発生源を、刃の前の上の角の Attachment(上向きに傾けたもの)にした。重力の加速を -35 から -12 に弱め、消える直前の大きさを 0.3 にした(仕様書の 0.3〜0.5)。
6. **直書きの数字**: 粒子の回転の範囲、土ぼこりの発生源の高さ・長さを、`Config.luau` に移した。
