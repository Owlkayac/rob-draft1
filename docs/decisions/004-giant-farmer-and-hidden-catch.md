# 決定 004: 農家さんを巨人(2.5倍)にする / 近すぎたら潜っていても捕まる / 天敵を拡張しやすい設計にする

- 日付: 2026-11-03
- 決めた人: 開発者(最初のバージョンを遊んでの感想として、音声で依頼)

## 決めたこと
1. **潜っていても、ごく近くまで来られたら捕まる**。隠れられるが、無敵ではない。
2. **農家さんは、ザリガニから見て巨人**。農家さんを2.5倍にする。ザリガニは小さくしない。
3. **天敵の動きは、季節などをあとから足せるように、部品に分けて、拡張しやすく設計する**。

## Claudeが選んだ案(あとで変えられる)
- 倍率は、開発者が「2.5倍から」と指定した。`Config.FarmerScale` で変えられる。
- 「距離」の数字(捕まえる距離、見回り地点に着く距離、経路探索の大きさ)は、大きさに比例させる。
- **歩く速さは、比例させない**。音声では、速さも比例させる方針を伝えたが、2.5倍にするとザリガニ(速さ16)に追いつけなくなり、遊べなくなるため、変えた。`Config.FarmerSpeedMultiplier`(いまは1.0)で、あとから変えられる。
- 発見できる距離(30)は、そのまま。
- 近すぎて捕まる距離(潜っているとき)は、標準サイズ基準で2(実際は5)。通常の捕まえる距離(基準4、実際10)より、短い。
- 季節そのものは、まだ作らない。補正を足す場所だけを用意する。

## 作ってみてわかったこと・追加の判断
- **潜るときの効き方**: 追跡中に潜られると、農家さんは、最後に見えた位置の近く(10以内)で止まって探す。この距離は、潜っていて捕まる距離(5)より大きいので、追跡中に潜っても、その場では捕まらない。潜っていて捕まるのは、主に、見回り中や探している最中の農家さんが、ザリガニの近く(5以内)を通ったとき。浮上したときに、農家さんが10以内にいれば、通常の捕獲で捕まる。詳しくは、仕様書002の節9。
  - 強すぎる・弱すぎると感じたら、`PatrolArriveDistance`、`FarmerCatchHiddenDistance`、`DiveMaxSeconds` を調整する。
- **足元の高さ**: 巨人にしたあとに、地面にめり込んだり浮いたりしないよう、モデルを置いたあと、1フレーム待って、モデルの底がゆか上面に合うように補正する。
- **大きくする方法**: `Model:ScaleTo` を使う。失敗したときは、モデルは1倍のままなので、距離の数字も実際の倍率に合わせる。
- **拡張のしかた**: `docs/design/enemy-architecture.md` に、新しい天敵(サギなど)・行動・補正(季節など)の足し方を書いた。季節そのものは、まだ作っていない。
- **確認できていないこと**: ロブロックスでの動作(特に、農家さんの足元の高さ、経路探索、簡易モデルの代替)は、まだ確認していない。

## 見直す時期
遊んでみて、巨人の怖さ、捕まる距離、速さが、しっくりこなければ、Config の数字だけを変える。
