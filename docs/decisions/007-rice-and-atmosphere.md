# 決定 007: 稲を「株」で作って連続して育て、刈り株と素材の質感を足す(光と空気は別の担当)

- 日付: 2026-11-03
- 決めた人: 開発者(遊んでの感想として依頼)

## 開発者の感想と依頼
「穂がついている演出がなく、稲が全く変わらない。刈った感じもしない。質感がない。これからどんどん質感を高めて、臨場感あふれる形にしていきたい」。仕様書は `docs/specs/007-rice-and-atmosphere.md`。

## 決めたこと
- **稲は「株」で作る**: 1株 = 葉3枚(細長い板)+ 穂2本(細い円柱)。1本の箱はやめた。
- **連続して育つ**: 3段階の高さではなく、ラウンドの進み具合(0〜1)に合わせて、高さ・色(緑 → 黄緑 → 黄金)・穂(出穂から現れて、大きくなり、垂れる)が、少しずつ変わる。段階(1〜3)は、天敵の発見距離の倍率と、稲刈り機の出番にだけ使う。
- **刈り株**: 稲刈り機が通った株は、短く(0.5)薄い黄色になり、穂が消え、そのラウンドの間は育たない。「もう一度」で戻る。
- **素材で質感を出す**: ゆか=泥(Mud)、あぜ=草(Grass)、葉=草(Grass)、穂=砂(Sand)、水面=ガラス(Glass)の薄い板。外部の素材は使わない。

## Claudeが選んだ案(あとで変えられる)
- **部品の数**: 20×20=400株 × 5 = 約2,000個。Model にはせず、Rice フォルダの下に部品を直接置き、サーバー内の表で株を持つ(軽くて扱いやすいため)。全部 Anchored、当たり判定なし、影なし。
- **更新間隔**: 育つ見た目は `RiceGrowthUpdateSeconds`(10秒)ごと、または段階が変わったとき。同じ値の代入は飛ばす。`BulkMoveTo` は、大きさ(Size)も変わるため使わない。
- **刈る処理**: 稲刈り機が動くたびに(毎フレーム)、長方形を囲む格子の範囲の株だけを調べる。
- **乱数のシード固定**: `Random.new(Config.RiceRandomSeed)`。やり直しても、同じ配置。
- **水の層**: 厚さ0.2の薄い板をゆか上面の上に重ねる。当たり判定・探索なしなので、歩く高さや天敵の足元は変わらない。透明度0.6、反射0.1。
- 稲の見た目が田んぼ全体で1つ(いちばん新しく始めたプレイヤーに合わせる)なのは、これまでと同じ。複数人の対応は、まだしない。

## 光と空気(クライアント)

### 決めたこと
- 光と空気は、**クライアントの端末だけ**で変える。サーバーの Lighting は触らない(クライアントで Lighting を変えると、その端末だけに反映される)。
- ラウンドの進み具合(0〜1)は、既存の RoundState(残り秒数)から `1 - 残り秒数 / RoundSeconds` で計算する。**新しい通信(RemoteEvent)は足さない**。
- Cleared のときは 1(いちばん夕焼け)。Caught のときは、捕まった時点の進み具合のまま。

### Claudeが選んだ案(あとで変えられる)
- **時刻**: 朝7時 → 夕方17時30分(`ClockTimeStart` / `ClockTimeEnd`)。
- **霧(Atmosphere)**: 密度と Haze は「朝(少し濃い)→ 昼(晴れる)→ 夕方(金色のもや)」の3点で補間。色・Decay・Glare・Offset は朝と夕方の2点。基準値は Config の `LightAtmo...`。
- **色補正**: 終盤に、暖かい色合い(TintColor)、Contrast +0.1、Saturation +0.15。**にじみ(Bloom)**: Intensity 0.2 → 0.6、Size 18 → 32。**SunRays**: Intensity 0.03 → 0.1(強くしすぎない)。
- **Lighting 本体**: Brightness、Ambient、OutdoorAmbient も朝と夕方で補間(Config の `LightBrightness...` など)。
- **なめらかに近づける方法**: `RenderStepped` で、現在値を目標へ指数的に近づける(`LightSmoothRate`)。フレームの長さに左右されない。値が変わらないフレームは、何も代入しない。
- **朝へ戻す扱い**: 進み具合が `LightResetDropThreshold`(0.05)以上下がったら新しいラウンドとみなし、速い `LightResetRate`(約0.5秒)で朝へ戻す。
- 効果の Instance は Lighting 直下に名前で探し、なければ作る(二重に作らない)。外部の素材(Sky のテクスチャなど)は使わない。

### 見直す時期
- 重い、まぶしい、霧が濃すぎると感じたとき。Config の `Light...` の数字で調整する(`docs/design/lighting.md`)。

## レビュー後の調整
1. **穂の垂れ**: `RiceEarDroopEndDeg` を 85 から 130 に変更(真上から130度 = 下向き気味)。穂の向きの計算は、1〜179度なら外積が 0 にならず、向きも逆にならない(コードでも 1〜179度に収める)。
2. **元からある効果**: Lighting 直下の Atmosphere などは、名前 → 同じ種類 → 新規作成の順で探す。元からあったものは `Stop()` で元の値に戻し、自分で作ったものだけ消す。同じ種類は2つ作らない。
3. **直書きを Config へ**: 葉の向きのずれ `RiceBladeYawJitter`、葉の長さの割合 `RiceBladeLengthFactorMin/Max`、色の切り替わり `RiceColorMidProgress`。素材名は FieldService 先頭の `MATERIAL_...` にまとめた。
4. **光の更新を軽く**: `LightUpdateEpsilon` を 0.00001 から 0.0005 に変更。
5. **小さな安全**: `Build()` で `SetGrowthProgress(0)` を Workspace に入れる前に呼ぶ。`CutRice` で列が nil のときを飛ばす。出穂の計算のゼロ割りを防ぐ(`math.max`)。`RiceEarDroopStartDeg` を 0 にしないよう、Config にコメントを追記。
