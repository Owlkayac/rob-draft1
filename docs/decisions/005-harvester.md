# 決定 005: 稲刈り機(終盤の危険)を作る

- 日付: 2026-11-03
- 決めた人: 開発者(「機能の追加を続けて」と依頼)。内容の細部は Claude が選んだ案

## 決めたこと
- 企画書(docs/game-concept.md)にあった「終盤は稲刈り機が動き出し、田んぼ全体が危なくなる」を、仕様書 006 で作る。
- 天敵の拡張設計(docs/design/enemy-architecture.md)の、2種類目の天敵として足す。

## Claudeが選んだ案(あとで変えられる)
- **潜っていても轢かれる**: 機械は「見つける」のではなく、ただ通るので、潜って隠れても逃げ道にならない。動いてよけるしかない。
- **遅い(速さ 13)**: ザリガニ(16)より遅いので、横に逃げればよけられる。
- **西から入って南北に往復する**: 田んぼの西のはしの1本目の線から始め、線ごとに東へ幅(14)ずつずれる。実装では、北のはしの外から入り、北→南→北…と往復する。最後の線を終えたら田んぼの外に出て、消える。
- **刈った稲は消えない**: 見た目の作り込みは、今回は作らない。
- **予告の文言**: 稲が「出穂」(段階3)になったとき、画面の上に「稲刈り機が動き出した!」と数秒間出す。動き出すのは、その3秒後。
- 【2026-11-03 変更】稲刈り機が、ラウンドの終わる前に走り切れるように、出穂の始まりを225秒から170秒にした(`GrowthStageSeconds` を `{75, 170}` に)。【2026-11-03 再変更】仕様書014の速さのゆらぎの最悪の場合を入れて、`{75, 165}` に変えた(決定 014 を参照)。経路は約1500スタッド(線9本 × 156 + 線の間のずれ)で、速さ13なら約117秒かかるため。
- 線の数は、東のはしまで取りこぼしなく刈れるように `ceil((xEast - x0) / HarvesterWidth) + 1` にした。最後の線だけ東の限度に固定し、前の線と重なってよい。
- **速さ・幅・出穂の始まりの関係**: 経路の長さ ÷ 速さ + 入るまでの時間 < ラウンドの残り時間(`RoundSeconds` - 出穂の始まり)。速さや幅、余白を変えたら、この式で出穂の始まり(`GrowthStageSeconds` の2つめ)を見直すこと。
- 出番は、稲が出穂の段階になった人がいるとき。つかまった・クリアしたら、稲刈り機は消える。「もう一度」でも消える。

## 見直す時期
遊んでみて、難しすぎる・簡単すぎると感じたとき。`Config.luau` の `HarvesterSpeed`、`HarvesterWidth`、`HarvesterLength`、`HarvesterLaneMargin`、`HarvesterEntryDelaySeconds` を調整する。
