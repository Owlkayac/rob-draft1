# 決定 006: プレイヤーの見た目を、図形で組んだザリガニにする

- 日付: 2026-11-03
- 決めた人: 開発者(「逃げるのをザリガニの見た目にしたい」と依頼)

## 決めたこと
プレイヤーは、人型ではなく、赤いザリガニの見た目で遊ぶ。仕様書は `docs/specs/005-crayfish-look.md`。

## Claudeが選んだ案(あとで変えられる)
- **人型を、動きと当たり判定の土台に使う**。操作とカメラは、Robloxの標準をそのまま使えるため。人型の見た目は、すべて透明にして隠し、図形(Part)で組んだザリガニを、HumanoidRootPart に溶接してついて歩かせる。
- **ザリガニは小さくしない**。小さくすると、操作やカメラに影響が出やすいため。「ザリガニから見た巨人」は、農家さんを大きくする(決定004)ことで表している。
- **外部の素材は使わない**。胴体、しっぽ、はさみ、目、ひげ、足、すべて、図形と色だけ。
- **歩く・潜るアニメーションは、まだ作らない**。潜るときは、半透明になるだけ。
- 見た目の細かい寸法(はさみの大きさ、足の太さなど)は、形の細部なので、`CrayfishModel.luau` の中の定数にした。調整しやすい大きさ(全長、高さ、色)だけを、Config に置いた。
- 人型の見た目を隠すのに失敗したときは、人型を隠さない(プレイヤーが見えなくならないように)。
