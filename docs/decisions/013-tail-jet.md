# 決定 013: 尻尾のジェット

- 日付: 2026-11-03
- 決めた人: 開発者(依頼)と、Claude(数字の案)。仕様書は `docs/specs/013-tail-jet.md`。

## 依頼
「尻尾を使いジェットモードを追加したい。秒数はいいかんじで」(開発者)。

## 決めたこと
- 尻尾をはじいて一気に進む能力「ジェット」を足す。Q キー(スマホは画面ボタン「ジェット」)。
- 秒数や倍率は、Claude に任された。

## 選んだ案(あとで変えられる)
- **0.8秒・2.4倍・ため直し8秒**: 0.8秒は「決定的な1発」で、操作できない時間が長くなりすぎない。2.4倍(約38)なら約30スタッド進み、農家さんの追跡(15)から一気に離れられる。8秒は、潜る(3秒+5秒)よりやや長く、いつでも使えて簡単になりすぎるのを防ぐ。
- **前に進む**: 本物のザリガニは後ろに進むが、遊びやすさのため前に進む。
- **サーバーが WalkSpeed を変え、クライアントが Move で進める**: 速さ(判定)はサーバーが決める(ずるができない)。クライアントは「入力がなくても進む」ために、毎フレーム `Humanoid:Move` を呼ぶだけ。
- **向きは噴射の瞬間に固定**: 動かしている向き、なければザリガニの向いている向き。噴射中は変えられない。
- **ため直しは、噴射の終了から**: 発動からではなく、噴射が終わってから8秒。生まれ直し・死亡でリセット(すぐ使える)。つかまった・クリアでは、噴射だけ止める。
- **潜る処理との関係**: 潜っている間はジェットできない。ジェット中は潜れない。
- **尻尾**: 尻尾の節とひれを1つの Motor6D(`Tail`)で動かす。歩くときのゆれは作っていない(任意だったため)。尻尾を下に丸めると、地面に少しめり込んで見える(当たり判定はない)。
- **音**: `Jet` の仕組みだけ作り、ID は空のまま。

## 見直す時期
- 強すぎる・弱すぎると感じたとき: `Config.luau` の `JetSeconds`、`JetSpeedMultiplier`、`JetCooldownSeconds` を変える。
- 尻尾の丸め方が見た目に合わないとき: `CrayfishTailCurlDeg` など。

## レビュー後の調整(2026-11-03)
1. **噴射の粒子の位置**: 粒子を、回る尻尾のひれではなく、胴体に溶接した見えない部品 `JetNozzle`(尻尾の先の少し後ろ)につけた。尻尾を丸めている間も、粒子は後ろに出る。
2. **Q 連打**: サーバーは、`LastJetRequestAt` を「発動したとき」だけ更新する(捨てた要求では更新しない)。クライアントは、噴射中・ため直し中は、お願いを送らない。
3. **尻尾の丸め角**: 65度 から 45度 へ(先が床の下に入りすぎないように)。In + Hold + Release の合計(0.75秒)は、JetSeconds(0.8秒)以下にする。
4. **噴射の向き**: 押した瞬間の、動かしている向きを覚え、噴射が始まったときに使う。止まっていたら、向いている向き。噴射が終わったら、覚えた向きを消す。
5. **尻尾の姿勢**: 潜った(`Hidden`)ときは、尻尾を、まっすぐに戻す。
6. **小さな点**: 表示は、変わったときだけ書き換える。更新間隔は `JetGuiUpdateSeconds`(0.1。0 にしない)へ。character がないときは、前の表示を保つ。フォントは `SourceSansBold`。
7. 仕様書の数値表に、`JetWaitSeconds`、`JetGuiUpdateSeconds` を足した。
