# 決定 014: 天敵の動きにランダム性を足す / 気づく演出を足す(サーバー側)

- 日付: 2026-11-03
- 決めた人: 開発者(依頼)と、Claude(数字と、細かい作りの案)。仕様書は `docs/specs/014-enemy-presence.md`。
- 範囲: この記録は**サーバー側**(仕様書 014 の 1・2)。クライアントの演出(巨人の歩き、足音の揺れ、緊張、心臓の音。仕様書 014 の 3)は、下の「クライアントの演出」の節に書いた。

## 依頼
「もう少し天敵の動きにランダム性を出してみて。臨場感をさらに強めて」(開発者)。

## 決めたこと
- 「予測できない怖さ」(ランダム性)と、「巨人が迫ってくる実感」(演出)の2つを足す。ただし、**理不尽にはしない**(最低限の公平さを、数字で守る)。
- 外部の素材は使わない。音のID(`FarmerNoticed`、`FarmerStep`、`Heartbeat`)は、場所だけ用意して空のまま。

## 選んだ案(あとで変えられる。数字はすべて Config.luau)
- **見回りの行き先**: 確率 0.5 で「田んぼの中のランダムな点(壁から15以上はなす)」、そうでなければ「見回り地点(直前の地点以外)」。固定の順番だと、2周目で動きが読めてしまうため。
- **立ち止まり**: 着いたとき確率 0.4 で、1〜3秒止まり、きょろきょろする(向きを、いまの向きから±100度の範囲で、時間の半分ずつ2回変える)。向きは、立ち止まっている間だけ、`Root.CFrame` の向き(横回りだけ)を少しずつ変えて作る(`Movement.TurnToYaw`)。`Humanoid:MoveTo` で近くの点を指すより、歩き出してしまう心配がなく、確実なため。
- **速さのゆらぎ**: 見回りは、1回の移動ごとに±12%。
- **勘**: 8〜14秒ごとに、確率 0.5 で、いちばん近い遊んでいるプレイヤー(潜っていても数える)の、半径22のずれた場所へ向かう。見つけたことにはならない(発見の判定は、これまでどおり)。
- **気づく間(`Notice` 行動)**: 見つけたら、すぐ走らず、0.4〜0.9秒、立ち止まって相手のほうを向く。その間に見えなくなれば「探す」。これが、プレイヤーが逃げ出す最初の猶予になる。判断は0.2秒ごとなので、実際は最大0.2秒ほど長くなる。
- **ダッシュとつまずき**: 追跡中、4〜9秒ごとに1秒だけ1.12倍。6〜14秒ごとに0.35秒だけ止まる。どちらも、前のが終わってから次の間隔を数える。
- **速さの上限 1.05倍**: 追跡の速さは、`CrayfishWalkSpeed × 1.05`(16.8)を超えない。追跡15 × ダッシュ1.12 = 16.8 でちょうど上限。ザリガニ(16)よりわずかに速いだけなので、ダッシュ中でも、ジェット(2.4倍)や潜るで逃げられる。`Stats` の補正ではなく、基本の数字 `ChaseSpeedMax` として持ち、`Chase` が `min` で止める(季節などの補正が `ChaseSpeed` をかけても、上限は別に守られる)。
- **見失う時間・探す時間**: 3〜6秒 / 2〜5秒のランダム(追跡・探すに入るたびに決める)。探すあいだは、最後に見えた位置の半径18の中を、1〜2か所歩く。古い `FarmerLoseSightSeconds`、`FarmerSearchSeconds` は、最小・最大に置き換えて、取りのぞいた。
- **公平さの保証**:
  - 出現(作られたとき・「もう一度」)から3秒は、見回り・探すで、プレイヤーを見つけない(追跡・気づく中は影響しない)。
  - 気づいてから走るまで、最低0.4秒。
  - 追跡の速さの上限(上のとおり)。
  - ランダムな動きは、すべて短い・小さい範囲にとどめ、勝ち負けを運だけで決めない。
- **稲刈り機の西/東**: 出番になるたび(出現するたび)に、ランダムで西か東から入る。東のときは、経路の点の x を `-x` にする(順番・長さ・線の数は同じ)。刈り残しは出ない(下の数式)。速さは、線ごとに±8%(線と線の間をつなぐ動きは、前の線と同じ倍率)。
  - 線の中心は、西から `x0 = -53`、幅14ずつ(-53, -39, -25, -11, 3, 17, 31, 45)、最後だけ `xEast = 53`。各線は±7を刈るので、-60 から 60 まで、すきまなく覆う(隣の線との間のすきまは0。最後の線は、前の45と重なる)。
  - 反転すると 53, 39, 25, 11, -3, -17, -31, -45, -53。左右対称なので、やはり -60 から 60 まで、すきまなく覆う。東の端の刈り残しが、西の端に出ることもない(余白 `HarvesterLaneMargin` が左右同じため)。
  - 経路の長さは、どちらも1510(9本 × 156 + ずれ106)。最悪の場合(全部の線が0.92倍): 1510 ÷ (13 × 0.92) ≒ 126.3秒。出穂165秒 + 3秒 + 126.3秒 + 最大1.2秒(段階更新の1秒刻みと、判断の間隔) ≒ 295.5秒 < 300秒で、収まる(`GrowthStageSeconds` の2つめを170から165にした。レビュー後の調整)。**ゆらぎを大きくするなら、`GrowthStageSeconds` の2つめを見直すこと**(Config にもコメントがある)。
- **状態の公開と、頭の上の表示**: 行動が切り替わるたびに、農家さんのモデルに Attribute `EnemyState`(`Patrol` / `Notice` / `Chase` / `Search`)をつけ、頭の上の BillboardGui `StateSign` を切り替える(Notice・Chase = 赤い「!」、Search = 黄色い「?」、Patrol = 非表示)。サイズ・高さは `FarmerScale` 倍。稲刈り機には `EnemyState` をつけない(クライアントが、農家さんと見分けられるように)。

## 作ってみて気をつけたこと
- 立ち止まっている間の向きの変更は、判断の間隔(0.2秒)ごとなので、動きが少しカクつく可能性がある。Studio で見て、気になるなら、別の方法(毎フレームの滑らかな回転)にする。
- 農家さんの頭の上の表示の高さは、頭の大きさと帽子から計算している。Studio で、帽子と重なっていないか確かめてほしい。
- 稲刈り機は、出現した直後の1フレームだけ、西の入り口にいてから、東か西の入り口へ置かれる(入り口は田んぼの外)。

## 見直す時期
- 理不尽・つらいと感じたとき: ダッシュ(`FarmerBurstMultiplier`、`FarmerBurstSeconds`)、気づく間(`FarmerNoticeSecondsMin`)、`FarmerStartGraceSeconds` を調整する。
- 簡単すぎるとき: `FarmerPauseChance` を下げる、`FarmerHunchChance` を上げる、`FarmerLoseSightSecondsMax` を大きくする。
- 動きを再現して直したいとき: `EnemyRandomSeed` を 0 以外にする。
- 調整のしかたの表は `docs/design/enemy-behavior-random.md`。

## クライアントの演出(仕様書 014 の 3)
実装: `src/StarterPlayer/StarterPlayerScripts/Controllers/EnemyPresenceController.luau`。数字はすべて Config の `Farmer...`。説明は `docs/design/enemy-presence.md`。

### 決めたこと
- **巨人の歩き**: 農家さんの関節(Motor6D)の `Transform` を、クライアントだけで動かす(ザリガニの足の動き(仕様書 010)と同じ方式)。足・膝・腕・腰・首。`Notice` は腕を上げ、`Search` は首をふり、止まっているときは息づかい。
- **足音の揺れ**: 足が地面につくたびに、自分のカメラが上下にはねて、すぐ戻る。近いほど強い。
- **近づく緊張**: `Notice`・`Chase` の農家さんが近いほど、画面が赤く・暗く・鮮やかになる。離れる・探す・見回りに戻ると、なめらかに戻る。
- **心臓の音**: 緊張しているあいだ、くり返し鳴り、強いほど大きい。

### 選んだ案
- **歩いた距離で足音を決める**: 時間ではなく「歩いた距離」で位相(動きの進み具合)を進める。速く歩くほど速く動き、止まれば動きも足音も止まる。足が地面につく瞬間は、位相が π ごと(= 1歩ごと。`FarmerStrideStuds` スタッドに1回)。足の1往復は2歩。(仕様書の「`FarmerStrideStuds / 2` ごと」は、位相の式「距離 / `FarmerStrideStuds` × π」と食い違うため、足の見た目と足音が合う「1歩 = `FarmerStrideStuds`」にした。)
- **`CameraOffset` で揺らす**: カメラの専用スクリプトを書き換えず、`Humanoid.CameraOffset` に「足した分だけ引く」やり方で書く。ほかの機能が使っても干渉しない。重なっても、最大値(`FarmerShakeMaxOffset`)を超えない。
- **別の ColorCorrection を重ねる**: 光の演出の "FieldColorCorrection" には触らず、専用の "FieldThreatColorCorrection" を足して重ねる。`LightingController` が「同じ種類の最初の1つ」を拾って取り違えないよう、専用のほうには Attribute `SeparateEffect` をつけ、`LightingController` はそれを飛ばす(小さな修正)。
- **IDが空なら鳴らさない**: 足音・気づいた音・心臓の音は、ID が空(いまの状態)なら Sound を作らない。エラーも警告も出ない。
- 関節が見つからない簡易モデルは、飛ばす(エラーにならない)。`EnemyState` を持たないもの(稲刈り機)は対象外。

### 見直す時期
- 揺れが強すぎる・弱すぎる: `FarmerShakeMaxOffset`、`FarmerShakeDecaySeconds`、`FarmerShakeMaxDistance`。
- 画面が暗すぎる・赤すぎる: `FarmerThreatBrightness`、`FarmerThreatTint`、`FarmerThreatSaturation`。
- 足の動きが速すぎる・遅すぎる、足音の間隔: `FarmerStrideStuds`。

## レビュー後の調整
1. **ラウンド後に「!」・赤い画面・心臓の音が残る問題**: 遊んでいる人が1人もいなくなったら(クリア・稲刈り機に捕まった、など)、`Chase` の `Update` が、すぐ `"Patrol"` を返す(`Perception.Scan` が入れる `ctx.AnyPlaying` を使う)。`EnemyState` が `Patrol` になり、頭の上の表示が消え、クライアントの赤い画面と心臓の音も止まる。
2. **巨人の足の動きの保険**: クライアントで、農家さんの水平の速さを「`AssemblyLinearVelocity`」と「前フレームとの位置の差 ÷ dt」の大きいほうにした。サーバー所有の NPC の速度が0に見えても、足・足音・揺れが出る。位置の差が `FarmerMaxPlausibleSpeed`(60)を超えたら、テレポート(やり直し)とみなして、位置の差は無視する。
3. **稲刈り機が走り切る余裕**: `GrowthStageSeconds` の2つめを170から165にした(最悪でも約295.5秒)。
4. **`Chase` の `Exit`**: つまずき・ダッシュの記憶を捨て、`WalkSpeed` を通常の追跡の速さ(上限つき)に戻す。つまずき中(0)のまま、次の行動に残らない。
5. **見回りの保険**: 行き先に `FarmerPatrolTargetTimeoutSeconds`(20秒)以内に着かなければ、その行き先を捨てて選び直す。
6. **小さな直書き**: 心臓の音量の更新のしきい値 0.005 を `FarmerHeartbeatVolumeEpsilon` にした。
