# 決定 008: 風で稲をゆらす(クライアントだけで動かす)

- 日付: 2026-11-03
- 決めた人: 開発者(「全て番号順に実装」という依頼のうちの1つ。決定007の「次の質感の候補」1番)。仕様書は `docs/specs/008-rice-sway.md`。

## 決めたこと
- **クライアントだけで動かす**: 各自の端末で稲を動かす。サーバーの負担も、通信(RemoteEvent)も増やさない。
- **株ぜんたいを回す**: 葉と穂を別々に曲げず、1株の部品すべてを、根もと(Root)を中心に同じ角度で回す。
- **近くだけ**: 自分のキャラクターから `RiceSwayRadius`(40)以内の株だけをゆらす(約100株)。外に出た株は元の位置に戻す。
- 刈り株になった株は、ゆらさない。見た目だけで、農家さん・稲刈り機・捕まる判定には影響しない。

## Claudeが選んだ案(あとで変えられる)
- **サーバーの変更は2つだけ**: 株ごとに Folder(`Plant_ix_iz`)に部品を入れる(Rice の下)。Folder に Attribute `Root`(Vector3)と `Cut`(boolean)をつける。育つ・刈る・やり直しの処理、乱数、部品の数と形は、変えない。部品の名前は `Blade1〜3`、`Ear1〜2`。
- **「元の位置」の覚え直し**: 部品ごとに `Base`(サーバーが決めた位置)と `Last`(クライアントが最後に書いた位置)を持つ。更新のとき、いまの位置が `Last` と大きく違う(位置 0.02 スタッド超、または向きの内積が 0.9999 未満)なら、サーバーが変えたとみなして `Base` をいまの位置にする。小さな差は、書いた値と読んだ値の誤差として無視する。数字は Config の `RiceSwayRebaseDistance` / `RiceSwayRebaseDot`。
- **刈った株の扱い**: 葉の高さを見る方法はやめて、Folder の Attribute `Cut` を見る(確実で軽い)。FieldService が、刈るとき(位置を変える前)に true、ResetRice で false にする。ゆれている途中で刈られたら、いったん元の位置へ戻してから止める(サーバーの新しい位置が先に届いていれば、それを新しい元の位置にする)。
- **更新間隔**: `Heartbeat` で時間をため、`1 / RiceSwayHz` 秒ごとに更新する(毎フレームではない)。
- **ゆれの式**: 角度 = `RiceSwayMaxDeg` × 強風の強弱 × sin(2π × 時間 / `RiceSwayPeriodSeconds` + 位相)。位相は、株の位置を風の向きに投影した距離 / `RiceWindWaveLength` × 2π。強風の強弱は、周期の違う sin を2つ重ねて、`RiceWindGustMin`(0.4)〜`RiceWindGustMax`(1.0)の間を往復。風の向きは `RiceWindDirWobbleDeg`(±5度)だけゆっくりふらつく。風の向き 0度 = +Z、90度 = +X。
- **作り直しへの備え**: Rice の `ChildAdded`/`ChildRemoved` で株を拾い・消す。`Workspace` に新しい `Field` が来たら拾い直す。壊れた株(Parent が nil)は表から消す。

## 見直す時期
- 重いと感じたら: `RiceSwayRadius` と `RiceSwayHz` を下げる。
- ゆれが大きい・小さいと感じたら: `RiceSwayMaxDeg`(傾きの最大)。
- 稲がよける動き、風の効果音は、まだ作らない(仕様書 008 の 5)。

## レビュー後の調整(2026-11-03)
1. **波の向き**: 波が風上へ流れて見えていたので、`sin(wave - 位相)` に直した(波の山が風下へ流れる)。傾きは「風下側だけ」にして、角度 = 最大 × 強風の強弱 × (0.5 + 0.5 × sin(...))。風下に傾いて戻る。
2. **古い待ちの扱い**: 田んぼが作り直されたときの片付け(`clearRice`)は、待ちの番号(`attachToken`)を変えない。番号を増やすのは、新しい Field を待ちはじめるときと Stop だけ。Field が消えたかは、`IsDescendantOf(Workspace)` で見る。
3. **軽くする**: 範囲の外の株では `Cut` を読まない。透明(Transparency 1)の部品は、位置を書かない(見えるようになったら含める)。
4. **0 で割らない**: `RiceSwayHz`、波の長さ、各周期は、コード側で小さな正の数に直して使う。
