# 決定 002: 最初は一人用、将来は複数人

- 日付: 2026-11-03
- 決めた人: 開発者

## 決めたこと
- 最初のバージョンは**一人用**にする。
- 将来の更新で、**複数人で同じ田んぼに入れる**ようにする。

## 最初の版での遊ばせ方(案)
- 1つのサーバーに入れるプレイヤーを1人にする(Studioのゲーム設定で最大人数を1にする)。
- 最大人数の設定は、複数人に対応するときに増やすだけでよい。

## 設計の約束(あとで複数人にしやすくするため)
- プレイヤーごとの状態(生きているか、潜っているか、スタミナ、経過時間など)は、`Player` をキーにした表で持つ。1つの変数に直書きしない。
- 天敵の「誰を狙うか」は、プレイヤーが1人でも複数でも動く書き方にする(いちばん近い生きているプレイヤーを狙う)。
- 複数人にする段階で、ラウンドの開始・終了の条件(全員が捕まったら終わり、など)を決める。

## 見直す時期
最初の版を遊んでもらい、一人用の反応を見た後。
