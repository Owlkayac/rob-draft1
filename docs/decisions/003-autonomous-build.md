## 判断の記録(Claudeが選んだ案。あとで変えられる)
### ゲームの流れと画面(仕様書003・004)
- 田んぼの向き: 北は -Z、南は +Z。スタート地点は南の端。
- 稲の見た目は、田んぼ全体で1つ。一人用の間は、いちばん新しく始めたプレイヤーの段階に合わせる。
- クリアしても、稲は最後の段階のまま。「もう一度」で最初の段階に戻る。
- `Players.RespawnTime` を非常に長くして、死んでも勝手に生まれ直さないようにした(「もう一度」を押したときだけ新しいラウンドが始まる)。Roblox メニューの「リセット」で倒れた場合も、「つかまった」扱いになる。
- つかまった後と、クリアした後は、歩けなくなる。
- 画面の文言・色・大きさは、GuiController の中の定数にした(Config には入れていない)。

### 天敵「農家さん」(仕様書002)
- 潜っている間は、近くにいても捕まえない。
- 狙う相手は、「遊んでいて、生きていて、見える条件を満たす人のうち、いちばん近い人」。
- 距離は、横方向(XZ)だけで測る。
- 潜って見失ったときは、最後に見えた位置に行って探す。遠ざかっただけで見失ったときは、最後に見えた位置で止まり、4秒後に見回りに戻る。
- 最初の出現位置は、スタート地点からいちばん遠い見回り地点(北西)。
- 農家さんの作成に失敗したときは、最大3回やり直し、それでも失敗したら、部品だけで作った簡易な人型を使う(警告が出る)。
- 歩くアニメーションと、効果音はない。
- 見回りの高さなど、細かい数字は Config にある。

### 将来(複数人にするとき)に作り直すところ
- 稲の段階、農家さん、やり直しの処理(`restartCallbacks`)が、全員で1つを共有している。
- キャラクターの位置は、Robloxの仕組み上、クライアントが持っている。ランキングや対戦を入れる前に、サーバーでの位置チェックを検討する。
