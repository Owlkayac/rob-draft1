# 仕様書 008: 風で稲がゆれる

> 状態: 実装済み(開発者の確認待ち)。仕様書007の「次の質感の候補」1番。開発者の依頼: 「全て番号順に実装」。
> 方針: ゆれは、**クライアント(各自の端末)だけ**で動かす。サーバーの負担と、通信を増やさない。外部の素材は使わない。

## 1. 何のための機能か
風で、稲が波のようにゆれて、田んぼの臨場感を出す。

## 2. ふるまい
- 稲の株(仕様書007)は、根もと(地面の点)を中心に、**株ぜんたいが、1つの固まりとして**、風の向きに、小さく傾いて、戻る、をくり返す。傾きは**風下側だけ**で、傾きの割合は 0〜最大の間を往復する(風下に傾いて戻る。風上へは傾かない)。式は「角度 = `RiceSwayMaxDeg` × 強風の強弱 × (0.5 + 0.5 × sin(波 - 位相))」。背が高い株ほど、先が大きく動いて見える。
- **風の波**: 株の位置によって、ゆれのタイミングをずらし(波の山が、風下へ流れていくように)、ゆれの大きさも、ゆっくり強弱をつける(ときどき、強い風が吹く)。
- 風の向きは、固定の1方向(`RiceWindDirectionDeg`)を基本に、ゆっくり、少しだけ、ふらつく。
- 近くの株だけゆらす: 自分のキャラクターから、一定の距離(`RiceSwayRadius`)以内の株だけ。外に出た株は、元の位置に戻す。更新は、1秒に `RiceSwayHz` 回(毎フレームでは、更新しない)。
- 刈り株になった株は、ゆらさない(刈ったあとは、止まる)。
- まだ見えない部品(出穂の前の、透明な穂)は、ゆらさない(見えるようになったら、ゆらす)。
- ゆれは、見た目だけ。農家さん・稲刈り機・捕まる判定には、影響しない。

## 3. 実装の方針(サーバーとクライアント)
- **サーバー(FieldService)**: 株ごとに、部品をまとめる入れ物(Folder)を作り、その中に、葉と穂を入れる。入れ物に、根もとの位置を、Attribute(`Root` : Vector3)として持たせる。名前は `Plant_番号`(格子の番号)。葉と穂は、これまでと同じ部品で、育つ処理・刈る処理は変えない。
- **クライアント(`RiceSwayController`)**: 近くの株の部品を、根もとを中心に、小さく回して、動かす。
  - サーバーが、育つ・刈るなどで、部品の位置を変えたときは、そのあとの位置を、新しい「元の位置」として、覚え直す。(クライアントが書いた位置と、読み取った位置が、わずかにずれる誤差を考えて、「大きく違うとき」だけ、サーバーが変えたとみなす。)
  - クライアントが動かした位置は、その端末だけで、他の人には見えない。サーバーには、送られない。
- 新しい RemoteEvent は、足さない。

## 4. 数値(Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| RiceSwayRadius | 40 | ゆらす範囲(キャラクターからの距離) |
| RiceSwayHz | 20 | 1秒の更新回数 |
| RiceSwayMaxDeg | 6 | 傾きの最大(度) |
| RiceSwayPeriodSeconds | 3.2 | 1回のゆれの周期 |
| RiceWindDirectionDeg | 20 | 風の基本の向き |
| RiceWindWaveLength | 30 | 波の長さ(この距離ごとに、ゆれの位相が1周する) |
| RiceWindGustPeriodSeconds | 11 | 強風の強弱の周期 |
| RiceWindGustMin / RiceWindGustMax | 0.4 / 1.0 | 強風の強弱の割合(いちばん弱いとき / 強いとき) |
| RiceWindDirWobbleDeg | 5 | 風の向きのふらつきの大きさ(度。±この値) |
| RiceWindDirWobblePeriodSeconds | 23 | 風の向きのふらつきの周期(秒) |
| RiceSwayRebaseDistance | 0.02 | 部品の位置がこれより動いたら、サーバーが変えたとみなす(スタッド) |
| RiceSwayRebaseDot | 0.9999 | 部品の向きの内積がこれより小さければ、サーバーが変えたとみなす |

注意: `RiceSwayHz`、`RiceWindWaveLength`、`RiceSwayPeriodSeconds`、`RiceWindGustPeriodSeconds`、`RiceWindDirWobblePeriodSeconds` は、割り算に使うので、0 にしない(コード側でも、小さな正の数に直して使う)。

## 5. 作らないこと
- 農家さん・稲刈り機・ザリガニが通ったときに、稲がよける動き
- 効果音(仕様書011で扱う)
- 風が、水面や光に影響すること

## 6. 重さ
- ゆらす株は、キャラクターの近くの、約100株。部品は約500個。1回の更新で、その数のCFrameを変える。重いと感じたら、`RiceSwayRadius` を小さく、`RiceSwayHz` を下げる。

## 7. 確認方法(Studioで遊んで確かめること)
1. 稲が、波のようにゆれている。ときどき、強く吹く。
2. 遠くの稲は、ゆれない(近くだけ)。歩くと、まわりの稲が、ゆれはじめる。
3. 稲刈り機が刈ったあとの株は、止まる。
4. 育つ・やり直しのとき、稲の高さや位置が、おかしくならない(ゆれのずれが、残らない)。
5. スマホのエミュレーターで、重くない。
