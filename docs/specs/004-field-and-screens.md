# 仕様書 004: 田んぼの舞台と、画面の表示(すべてコードで作る)

> 状態: 実装済み(開発者が遊んで確認)。数字は仮の初期値で、遊びながら調整する。
> 目的: 仕様書001〜003を遊べる形にするために、舞台(田んぼ)と画面を、Studioでの手作業なしに、コードから作る。

## 1. 田んぼの舞台(サーバーが、ゲーム開始時に作る)
- **ゆか**: 泥の色の大きな平らな板(Config.FieldSize × Config.FieldSize)。Anchored。(見た目は仕様書007で置き換えた)
- **あぜ(まわりの壁)**: ゆかの四辺に、高さ8の壁を立てる。ザリガニと天敵が外に出られない。
- **稲**: ゆかの上に、格子状(間隔 Config.RiceSpacing)に細い箱を並べる。(見た目は仕様書007で置き換えた)
  - 全部 Anchored、CanCollide=false、CanQuery=false(歩く邪魔にならず、経路探索にも影響しない)。
  - 高さは、成長の段階(仕様書003)で変わる。底は、いつもゆかにつけておく。
  - 色は、段階1・2は緑、段階3(出穂)は黄金色。
- **スタート地点**: 田んぼの南の端に、SpawnLocation を1つ置く(チームなし)。
- **見回りの地点**: 天敵(仕様書002)の見回り用に、田んぼの中に4〜5か所を決める。
- 作るものは、Workspace の中の `Field` というフォルダ(Folder)にまとめる。やり直すときに、作り直さず、状態だけ戻す。
- 既存の Baseplate(Studioで最初からある地面)は、触らない。田んぼは、Baseplateの上に置く。

## 2. 画面の表示(クライアントが、コードで作る)
- 画面の上の真ん中に、**残り時間(分:秒)**と、**いまの段階の名前**を出す。
- 「つかまった」画面: 画面の真ん中に大きな文字と、「もう一度」ボタン。
- 「クリア」画面: 「稲刈りの日まで生き延びた!」と、「もう一度」ボタン。
- 「もう一度」を押すと、サーバーにお願いを送り、最初からやり直す。
- 文字は、日本語。ボタンは、スマホでも押しやすい大きさ。

## 3. 通信(ReplicatedStorageに、サーバーが RemoteEvent を作る)
| 名前 | 向き | 内容 |
|---|---|---|
| RoundState | サーバー → クライアント | 状態(Playing / Caught / Cleared)、段階の名前、残り秒数 |
| RestartRequest | クライアント → サーバー | 「もう一度」のお願い(値なし) |

- RoundState は、Playing 中は1秒に1回、状態が変わったときにも送る。
- RestartRequest を受けたサーバーは、そのプレイヤーの状態が Caught か Cleared のときだけ、やり直す(型・間隔・状態を検証する)。

## 4. やり直しの流れ(サーバー)
1. 稲を、最初の段階(低い・緑)に戻す。
2. 経過時間を、0に戻す。
3. プレイヤーのキャラクターを生まれ直させる(`player:LoadCharacter()`)。
4. 天敵を、最初の見回りに戻す。
5. 状態を Playing にして、RoundState を送る。

## 5. 数値(仮。Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| FieldSize | 120 | 田んぼの一辺の長さ |
| FieldWallHeight | 8 | あぜの高さ |
| RiceSpacing | 8 | 稲と稲の間隔 |
| RiceHeights | 2, 5, 9 | 段階ごとの稲の高さ |
| RestartRequestMinInterval | 1 | 「もう一度」の受け付け間隔の最小値 |

## 6. 作らないこと
- 稲の細かい見た目(葉の形など)
- 水の動き、空の演出、音
- 田んぼ以外の舞台、障害物(岩、水路など)
- ステージ選択

## 7. 実装の注意
- 稲の数は 15×15=225 本程度に収まるように、間隔を決める(重くなりすぎないように)。
- 外部の素材(画像、モデル、音)は使わない。すべて、図形と色だけで作る。

## 8. 確認方法(Studioで遊んで確かめること)
1. ゲームを始めると、泥の田んぼと、緑の稲が並んでいる。まわりが壁で囲まれている。
2. 画面の上に、残り時間と段階の名前が出る。
3. 時間がたつと、稲が高くなり、最後に黄金色になる。
4. 捕まる、またはクリアすると、画面が出て、「もう一度」で最初に戻る。
