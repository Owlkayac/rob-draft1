# 仕様書 010: ザリガニの足の動き(アニメーション)

> 状態: 実装済み(開発者の確認待ち)。仕様書007の「次の質感の候補」3番。仕様書005の「歩くアニメーションは作らない」を、この仕様書で置き換える。
> 方針: 動きは、**クライアント(各自の端末)だけ**で動かす。サーバーの負担と、通信を増やさない。外部のアニメーション素材は使わない。

## 1. 何のための機能か
ザリガニが歩くと、足が動き、はさみとひげが動くようにして、生き物らしさを出す。

## 2. 動き
- **歩く**: 足が、左右、前後の組で、交互に前後にふる(カニ・ザリガニらしく、細かく)。速く歩くほど、速く動く。止まっているときは、足は止まる。
- **はさみ**: 歩くと、少し上下にゆれる。止まっているときは、ゆっくり、ゆれる(呼吸のように)。
- **ひげ**: 歩くと、後ろにたなびき、止まっているときは、ときどき、ふるえる。
- **しっぽ**: 歩くと、ほんの少し、左右にゆれる(任意)。
- **潜っているとき**: 動かない(姿勢を保つ)。
- 他のプレイヤーのザリガニも、同じように動く(将来の複数人のため。クライアントが、見えているすべての `CrayfishVisual` を動かす)。

## 3. 実装の方針
- **サーバー(`CrayfishModel`)**: 足・はさみ・ひげ(・しっぽ)の部品を、`WeldConstraint` ではなく、**`Motor6D`** で、胴体(または HumanoidRootPart)につなぐ。関節の位置(足の付け根など)が、回転の中心になるよう、`C0`(土台側の位置)と、`C1`(部品側の位置)を、設定する。動かない部品(胴体、しっぽの節、目など)は、これまでどおり WeldConstraint でよい。
  - Motor6D の名前で、種類が分かるようにする(例: `LegL1`、`LegR1`、`ClawL`、`ClawR`、`AntennaL`、`AntennaR`)。
- **クライアント(`CrayfishAnimator`)**: 毎フレーム(RenderStepped)、見えているキャラクターのうち、`CrayfishVisual` を持つものについて、各 Motor6D の `Transform` を、時間と速さから計算して設定する。`Transform` の変更は、その端末だけで、サーバーには届かない。
  - 速さは、`HumanoidRootPart.AssemblyLinearVelocity`(横方向)の大きさ、または `Humanoid.MoveDirection` から求める。
  - 潜っている(キャラクターの Attribute `Hidden` が true)ときは、更新しない。
  - 見えなくなったキャラクター(離れた、消えた)の分は、片付ける(接続やテーブルに、残さない)。
- 新しい RemoteEvent は、足さない。

## 4. 数値(Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| CrayfishLegSwingDeg | 28 | 足のふりの大きさ(度) |
| CrayfishLegCyclesPerStud | 0.35 | 1スタッド歩くときの、足の動きの回数 |
| CrayfishClawBobDeg | 6 | はさみの上下の大きさ |
| CrayfishAntennaWagDeg | 10 | ひげのふるえの大きさ |
| CrayfishIdleBreathSeconds | 2.4 | 止まっているときの、ゆっくりした動きの周期 |

## 5. 作らないこと
- 潜るときに、体が泥に沈んでいく動き(いまは半透明になるだけ)
- ジャンプ・向きを変えるときの特別な動き
- 農家さんや稲刈り機のアニメーション
- 外部のアニメーション素材

## 6. 注意
- Motor6D を使うと、足などの部品が、見た目の位置に、物理で固定される(いまの WeldConstraint と同じ)。当たり判定・重さは、変えない(`CanCollide=false`、`Massless=true`)。
- `CrayfishModel` は、仕様書007までの動き(潜るときの半透明、高さの作り直し)と、両立させる。部品が増える・名前が変わる場合は、`CrayfishService` の、潜る処理と合わせる。

## 7. 確認方法(Studioで遊んで確かめること)
1. 歩くと、足が、交互に動く。速く歩くと、速く動く。止まると、足は止まる(はさみは、ゆっくり、ゆれる)。
2. 潜っている間は、動かない。浮上すると、また動く。
3. 「もう一度」で生まれ直しても、同じように動く。見た目が、壊れない(足が、ばらばらに飛ばない)。
4. 重くない。
