# 仕様書 016: 天敵側のモード「農家さんになって、つかまえる」

> 状態: 実装済み(開発者の確認待ち)。実装の記録は `docs/decisions/016-farmer-mode.md`、仕組みの説明は `docs/design/farmer-mode.md`。開発者の依頼: 「天敵側をやるのも、選択してできるようにしたい」。
> 前提: 仕様書015(メニューと難易度)。メニューで「農家さん」を選ぶと、このモードになる。
> 最大プレイヤー数は1(決定002)なので、ザリガニは、**AI(コンピューター)が動かす**。

## 1. 何のための機能か
追われる側(ザリガニ)だけでなく、**追う側(巨人の農家さん)**を、自分で操作して、遊べるようにする。

## 2. ルール
- 田んぼに、**AIのザリガニ**が、`PreyCount`(やさしい2 / ふつう3 / むずかしい5)ひき、いる。
- プレイヤーは、**巨人の農家さん**を操作して、AIのザリガニを、**ぜんぶつかまえる**。
- **制限時間**: ふだんと同じ 300秒(稲が、稲刈りの日まで育つ)。
- **クリア**: ぜんぶつかまえたら、すぐクリア(早いほど、ボーナス)。
- **しっぱい**: 時間切れ(稲刈りの日になっても、にげられた)。
- 稲刈り機・餌・天敵のAI農家さんは、このモードでは、出ない(出番がない)。
- 稲の育ち・光・音・ラウンドの流れ・画面は、これまでと同じ。

## 3. プレイヤーの農家さん
- プレイヤーのキャラクターを、**2.5倍(`FarmerScale`)の巨人**にする(`Model:ScaleTo`)。麦わら帽子をかぶる(農家さんAIと同じ帽子)。外見は、プレイヤーのアバターのまま(帽子だけ足す)。
- 歩く速さ: `FarmerPlayerWalkSpeed`(15)。ジャンプは、できない。
- カメラ: 巨人に合わせて、遠くから見られるように、ズーム距離(`CameraMinZoomDistance`・`CameraMaxZoomDistance`)を、`FarmerPlayerCameraMin/Max`(20 / 60)にする(ザリガニのときは、元に戻す)。
- 操作: 歩くだけ(ジェット・潜るは、ない。画面にも出さない)。
- つかまえる: AIのザリガニと、農家さん(プレイヤー)の、横方向の距離が、
  - 潜っていないとき: `FarmerCatchDistance × FarmerScale`(10)以下
  - 潜っているとき: `FarmerCatchHiddenDistance × FarmerScale`(5)以下
  で、つかまえる(仕様書002・014と、同じ考え方)。つかまえたザリガニは、消える(Destroy)。

## 4. AIのザリガニ(`PreyService`、サーバー)
- 見た目: プレイヤーのザリガニと、同じ見た目と動き(`CrayfishModel` で、組んだもの)。人型の土台(Humanoid)を、`CreateHumanoidModelFromDescription` で作り、ザリガニの見た目をつけ、人型は隠す。Workspace の `Prey` フォルダに入れる。サーバーが動かす。
- 動き(状態):
  - **うろうろ(Wander)**: 田んぼの中の、ランダムな点に、歩く。ときどき立ち止まる。
  - **にげる(Flee)**: 農家さん(プレイヤー)が、`PreySightDistance × PreyAwarenessMultiplier`(35)以内に近づいたら、農家さんから**遠ざかる向き**へ、走る(壁ぎわでは、壁にそって、すべるように、向きを変える。壁に追いつめられると、つかまりやすい)。
  - **潜る(Hide)**: 農家さんが `PreyDiveDistance`(16)以内に近づき、潜れる(ため直しが終わっている)とき、確率 `PreyDiveChance`(0.5)で、潜る(`PreyDiveSeconds`(3)。動けない。半透明。Attribute `Hidden`)。潜る間隔のため直し: `PreyDiveCooldownSeconds`(7)。
  - **ジェット(Jet)**: 農家さんが `PreyJetDistance`(11)以内に近づき、使える(ため直しが終わっている)とき、確率 `PreyJetChance`(0.7)で、農家さんから遠ざかる向きに、`JetSeconds` のあいだ、`JetSpeedMultiplier` 倍の速さで走る(`PreyJetCooldownSeconds`(9))。
- 速さ: ふだん `PreyWalkSpeed`(13)× `PreySpeedMultiplier`。プレイヤーの農家さん(15)より、すこし遅い。
- 「判断のゆらぎ」: 反応に、ランダムな遅れ(`PreyReactionSecondsMin/Max`: 0.2〜0.5)を、つける(完璧に逃げない)。
- 出現: 農家さん(スタート地点は南端)から遠い、田んぼの北側で、ランダムに、ばらけて出る。出現から `PreyStartGraceSeconds`(3)は、にげない(うろうろ)。
- 判断のループ: `task.wait(EnemyTickSeconds)` ごと。壊れたモデル・いなくなったプレイヤーで、エラーにならない。

## 5. 点数・記録
- 点数 = つかまえたザリガニ × `PreyCatchPoints`(100)+ のこり時間 × `PreyTimeBonusPerSecond`(1)(クリアしたときだけ)+ クリアのボーナス(`ClearBonus`) 、 × `ScoreMultiplier`。
- ベスト記録は、「農家さん」×「なんいど」の組み合わせで、別に保存される(仕様書015)。
- 画面: 左上に「てん: N」と、「のこり: N ひき」。結果の文言は、このモードの専用(クリア「ぜんいん つかまえた!」、しっぱい「にげられた…」)。

## 6. 他の機能との関係
- **ザリガニのモード専用の機能**(潜る・ジェット・餌・稲刈り機・農家さんAI)は、このモードでは、出番がない(`IsActive` などで、止める)。
- **プレイヤーの入力**: 潜る・ジェットの要求が、このモードで来ても、サーバーが無視する(やくわりが `Farmer` のとき)。画面のジェットの表示も、出さない。
- **ラウンドの進行**: 時間切れ(300秒)は、これまでの `Cleared`(稲刈りの日)と同じ時刻に、「にげられた」として終わる(状態の種類は増やさず、`Caught` として扱う(時間切れ・見本が作れないとき・つかまえた数 0 の全滅)。点数の計算と画面の文言が違うだけ。サーバーの `RoundService` に、「やくわり」を渡して、終わり方を、分ける)。
- **将来(複数人)**: プレイヤーが、ザリガニ側と農家さん側に、分かれて遊べるようにする(いまは、AIが、相手)。

## 7. 作らないこと
- 農家さんの、ジャンプ・ダッシュ・特殊な技
- AIザリガニの、餌を食べる行動
- 難易度ごとの、AIの、細かい性格づけ
- 稲刈り機を、プレイヤーが操作すること
- 複数のプレイヤーでの対戦

## 8. 数値(Config.luau にまとめる)
`FarmerPlayerWalkSpeed`、`FarmerPlayerCameraMin/Max`、`Prey...`(`PreyWalkSpeed`、`PreySightDistance`、`PreyDiveDistance`、`PreyDiveChance`、`PreyDiveSeconds`、`PreyDiveCooldownSeconds`、`PreyJetDistance`、`PreyJetChance`、`PreyJetCooldownSeconds`、`PreyReactionSecondsMin/Max`、`PreyStartGraceSeconds`、`PreyCatchPoints`、`PreyTimeBonusPerSecond`、AIの見た目の設定)。割り算に使う値・時間は、0 にしない。

## 9. 確認方法(Studioで遊んで確かめること)
1. メニューで「農家さん」を選んで「スタート」すると、自分が、巨人の農家さん(帽子つき)になる。カメラが、引いて見える。
2. 田んぼに、赤いザリガニが、数ひき(やさしい2、ふつう3、むずかしい5)、うろうろしている。
3. 近づくと、ザリガニが、にげる。さらに近いと、潜る・ジェットで、にげる。
4. 近くまで行くと、つかまえられる(潜っていても、ごく近ければ)。つかまえると、消えて、点が増え、「のこり」が減る。
5. ぜんぶつかまえると、クリア。時間切れだと、「にげられた」。結果に、点数とベストが出る。
6. このモードでは、稲刈り機・餌・AI農家さんが出ない。潜る・ジェットの表示も出ない。
7. 「メニューへ」で戻り、ザリガニのモードに、切り替えられる。切り替えたとき、巨人・カメラが、元に戻る。
8. 「出力」にエラーが出ない。
