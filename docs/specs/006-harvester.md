# 仕様書 006: 稲刈り機(終盤の危険)

> 状態: 案(開発者の確認待ち)。企画書(docs/game-concept.md)にあった「終盤は稲刈り機が動き出し、田んぼ全体が危なくなる」を、この仕様書で作る。
> 天敵の設計(docs/design/enemy-architecture.md)に、2種類目の天敵として足す。拡張しやすい設計が、実際に使えるかの確認にもなる。

## 1. 何のための機能か
ゲームの終盤(稲が黄金色になる「出穂」の段階)に、田んぼ全体が危なくなり、「稲刈りの日」が近づく緊張感を出す。

## 2. ふるまい
1. **出番**: 稲の成長の段階3(出穂)になった瞬間に、画面に「稲刈り機が動き出した!」と出す。3秒後に、田んぼの西のはしから、稲刈り機が入ってくる。
2. **動き**: 田んぼを、南北に往復して刈っていく(草刈りのように)。1往復ごとに、少し東にずれる。
   - 経路: 北のはしの外から入り、西のはしの1本目の線の上を、最初は南へ向かう。線の端(田んぼの外)で向きを変え、次の線では北へ → その次は南へ … と往復する。線ごとに、東へ `HarvesterWidth` ずつずれる(ずれる動きは、田んぼの外で行う)。
   - 線の中心は、西の1本目 `x0 = -FieldSize/2 + HarvesterLaneMargin` から、東の最後 `xEast = FieldSize/2 - HarvesterLaneMargin` まで。線の数は `ceil((xEast - x0) / HarvesterWidth) + 1`(いまは9本)。最後の線だけ xEast に固定する(前の線と重なってよい)ので、東のはしまで取りこぼしなく刈る。
   - 線と線の間隔は、稲刈り機の幅以下(取りこぼしのないように)。
   - 最後まで刈り終えたら、田んぼの外に出て、消える(出番は終わり)。
   - 経路の長さは約1500スタッド。速さ13で約117秒かかる。ラウンドの終わる前に走り切るよう、出穂の始まりを早めた(仕様書003の `GrowthStageSeconds` を `{75, 170}` に変更。170 + 3 + 117 ≒ 290秒 < 300秒)。
3. **捕まえる**: 稲刈り機の**足元の範囲(長方形)**に、ザリガニが入ったら、捕まる。
   - **潜っていても、捕まる**(機械は、見つける・見つけないではなく、ただ通るため)。潜って隠れても、逃げ道にならない。動いて、よけるしかない。
4. **よけ方**: 稲刈り機の進行方向と、横方向へ逃げれば、よけられる。速さは、ザリガニより遅い。
5. **やり直し**: 「もう一度」でやり直したら、稲刈り機は消えて、次の出番まで、出ない。

## 3. 数値(仮。Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| HarvesterSpeed | 13 | 進む速さ(ザリガニ16より遅い) |
| HarvesterWidth | 14 | 刈る幅(長方形の、進行方向と直角の長さ) |
| HarvesterLength | 18 | 機械の長さ(進行方向) |
| HarvesterHeight | 10 | 機械の高さ(見た目のみ) |
| HarvesterEntryDelaySeconds | 3 | 出穂の段階になってから、入ってくるまでの時間 |
| HarvesterLaneMargin | 7 | 田んぼの西のはしから1本目の線まで、東のはしから最後の線までの距離 |
| HarvesterColor, HarvesterBladeColor | 黄緑、銀 | 色 |

## 4. 見た目(図形で作る・外部の素材は使わない)
- 胴体(大きな箱)、運転席(小さな箱)、前の刈り取りの刃(横長の箱。幅は HarvesterWidth)、車輪(円柱)4つ。
- すべて、CanCollide=false、CanQuery=false、CanTouch=false、Anchored=true(動きは、コードで、位置を毎フレーム動かす)。
- 色は、緑がかった機械の色と、銀色の刃。

## 5. 画面
- 段階3になったとき、画面の上に、数秒間、「稲刈り機が動き出した!」と出す(クライアントの GuiController が、段階の名前を見て、一度だけ表示する)。

## 6. サーバーで判定すること
- 稲刈り機の位置の更新と、捕まえる判定は、すべてサーバーで行う。
- 捕まえる判定: 遊んでいて生きているプレイヤーの HumanoidRootPart の位置が、稲刈り機の長方形(向きを考えた範囲。横幅 HarvesterWidth、長さ HarvesterLength)の中なら、`RoundService.NotifyCaught(player)`。**潜っているかどうかは見ない。**

## 7. 設計の約束(天敵の拡張設計を使う)
- 天敵の「定義」を足す形で作る(`Enemy/Definitions/Harvester.luau`)。新しい行動は `Enemy/Behaviors/Sweep.luau`。
- 農家さんと違う点を、定義が持つ**任意の関数**で表せるように、天敵の型(Types.luau)に、次の6つを足す(足さない天敵は、いまの動きのまま)。
  1. `IsActive`: 「いま、出番か」を決める関数。出番でない間は、モデルを置かず、判断もしない。
  2. `CheckCatch`: 「捕まえる判定」を、定義が自分で決められる関数。ない天敵は、いまの距離の判定を使う。
  3. `ResetOnCatch`: 捕まえたあと、最初の行動に戻すか。`false` なら戻さず、そのまま続ける(機械向け)。ない(nil)か `true` なら戻す。
  4. `FindBody`: モデルから体の部品(Humanoid と、位置の基準の部品)を探す関数。Humanoid を使わない天敵用。ない天敵は人型を探す。
  5. `IsModelUsable`: モデルがまだ使えるかを確かめる関数。Humanoid を使わない天敵用。ない天敵は人型の確認をする。
  6. `SkipScan`: `true` なら、毎回の「見回し」(見える相手を探す処理)をしない。見回しが要らない天敵向け。ない天敵は見回す。
- 稲刈り機は、Humanoid も、経路探索も使わない(位置を、コードで動かす)。
- 農家さんの動きは、変えない。
- docs/design/enemy-architecture.md に、「出番を決める」「捕まえ方を変える」の足し方を書き足す。

## 8. 作らないこと
- 刈った稲が消える見た目(稲は、そのまま)
- 効果音、土ぼこりなどの演出
- 稲刈り機に乗る、止めるなどの操作
- 稲刈り機が複数台になること

## 9. 確認方法(Studioで遊んで確かめること)
1. 時間を早める(Config の `RoundSeconds` と `GrowthStageSeconds` を小さくする)と、出穂の段階で、「稲刈り機が動き出した!」と出る。
2. 3秒後に、西のはしから、稲刈り機が入ってきて、南北に往復しながら、東へ進む。
3. 稲刈り機の範囲に入ると、「つかまった」になる。潜っていても、同じ。
4. 横に逃げれば、よけられる。
5. 「もう一度」で、稲刈り機が消えて、次の出穂まで出ない。
6. 農家さんも、いままでどおり動いている。
