# 仕様書 007: 稲の質感と、田んぼの臨場感

> 状態: 実装済み(開発者が遊んで確認)。開発者の感想: 「穂がついている演出がなく、稲が全く変わらない。刈った感じもしない。質感がない。これからどんどん質感を高めて、臨場感あふれる形にしていきたい」。
> 仕様書003の「稲の細かい見た目は作らない(高さ3段階だけ)」を、この仕様書で置き換える。仕様書004の「稲」「ゆか」の見た目も、ここで置き換える。
> 方針: Roblox に最初から入っている**素材(Material)、光(Lighting)、効果**だけで作る。外部の画像・音・モデルは使わない。

## 1. 稲を「株」で作り、育つ様子を見せる(サーバー)
- 稲を、1本の箱ではなく、**株(かぶ)**として作る。1つの株は、次の図形(Part)でできている。
  - **葉**: 細くて長い板を、3枚。少しずつ違う向きと傾きで、外側に開いて立てる(株ごとに、向きと傾きに、少しランダムをつける)。
  - **穂**: 細い円柱を、2本。育ちきる終盤に、先が垂れる(重みで下を向く)。
- 株の置き方: 格子状だが、位置に少しランダムなずれをつける(整列しすぎない)。間隔は `Config.RiceSpacing`(6に変更)。20×20=400株。
- **連続して育つ**: これまでの3段階ではなく、ラウンドの進み具合(0〜1)に合わせて、少しずつ育つ。
  - 高さ: `RiceHeightMin`(低い)から `RiceHeightMax`(高い)まで、なめらかに伸びる。
  - 色: 緑 → 黄緑 → 黄金色へ、少しずつ変わる。
  - 穂: 出穂の段階(段階3)に入ると、穂が現れ、時間とともに大きくなり、垂れていく。
  - 更新は、`Config.RiceGrowthUpdateSeconds`(10秒)ごと。1回で変える部品の数が多いので、毎フレームは更新しない。
- 葉には、芝生(Grass)の素材をつけ、質感を出す。穂は、砂(Sand)などの、つぶつぶした素材にする。

## 2. 稲刈り機が、稲を刈る(サーバー)
- 稲刈り機(仕様書006)が通ったあとの株は、**刈り株(かぶ)**になる。
  - 葉は、短く(`RiceStubbleHeight`)、色は薄い黄色。穂は、消える。
  - 刈った株は、そのラウンドの間、もう育たない。
- 判定: 稲刈り機の足元の長方形の中に、株の中心が入ったら刈る。毎フレーム、近くの株だけを調べる(田んぼ全体を調べない)。
- 「もう一度」(やり直し)で、すべての株が、最初の状態(低くて緑)に戻る。

## 3. 地面と壁の質感(サーバー)
- ゆか: 泥(Mud)の素材。色は、茶色。
- 水面: 泥の上に、浅い水の層を、薄い板で作る。半透明(0.6)、少し反射(Reflectance)、色は、茶色がかった青緑。当たり判定なし、稲の根もとが水に浸かって見える高さ(ゆか上面より少し上)。
- あぜ(壁): 草の生えた土(Grass)の素材。
- 見た目の素材は、Config に素材名を置かず、FieldService の中の定数でよい(色は Config)。

## 4. 光と空気(クライアント。画面ごとに、自分の端末だけで変える)
- 新しい部品 `LightingController`(クライアント)。サーバーから届く、いまの**ラウンドの進み具合**から、光を、なめらかに変える。
  - **時刻**: 朝(`ClockTimeStart`=7)から、夕方(`ClockTimeEnd`=17.5)へ。夕方に近づくと、夕焼けになる。
  - **空気**: `Atmosphere`(もや)を足す。朝は、うっすら霧がかかり(密度が少し高め)、昼に晴れ、夕方に、金色のもやになる。
  - **色**: `ColorCorrection` で、終盤を暖かい色合いに。`Bloom` で、光を少しにじませる。`SunRays` は、強くなりすぎない範囲で。
  - 稲刈りの日(クリア)のとき、いちばん夕焼けの状態にする。やり直しで、朝に戻す。
- すべて、Roblox に最初からある機能のみ。サーバーの Lighting は、変えない(クライアントが、自分の端末だけで変える)。
- 進み具合の知らせ: 既存の RoundState(残り秒数)から計算する。新しい通信は、増やさない。ラウンドの長さは `RoundSeconds`。

## 5. 数値(仮。Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| RiceSpacing | 6 | 株と株の間隔(8から変更) |
| RiceJitter | 1.2 | 株の位置の、ランダムなずれの最大 |
| RiceBladeCount | 3 | 1株の葉の数 |
| RiceHeightMin / Max | 2 / 9 | 稲の高さの、最小と最大 |
| RiceStubbleHeight | 0.5 | 刈り株の高さ |
| RiceGrowthUpdateSeconds | 10 | 育つ見た目の更新間隔 |
| 稲の色(緑、黄緑、黄金、刈り株) | | 色の変わり方の基準 |
| WaterTransparency / WaterReflectance | 0.6 / 0.1 | 水面 |
| ClockTimeStart / ClockTimeEnd | 7 / 17.5 | 光の時刻 |
| 霧・色補正・にじみの数値 | | 光と空気の基準 |

## 6. 作らないこと
- 稲が風でゆれる動き(あとで、クライアントで足す候補)
- 効果音、環境音(外部の音の素材が必要なため)
- 粒子の演出(土ぼこり、水しぶきなど)
- 雨や天気の変化
- 外部の画像・音・モデルを使うこと

## 7. 注意(重さ)
- 部品の数: 400株 × (葉3 + 穂2) = 約2,000個。すべて Anchored、CanCollide・CanQuery・CanTouch は false。
- 重いと感じたら、`RiceSpacing` を広げる(8に戻す)、`RiceBladeCount` を減らす、で調整する。
- 株の更新は、1回で数千の値を変える。10秒ごと以上の間隔にする。

## 8. 確認方法(Studioで遊んで確かめること)
1. 稲が、1本の棒ではなく、数枚の葉が開いた「株」になっていて、まばらにずれて並んでいる。
2. 時間がたつと、稲が少しずつ伸び、緑から黄金色へ変わる。出穂の段階で、穂が現れ、先が垂れる。
3. 稲刈り機が通ったところは、短い刈り株になり、穂が消える。刈られていない株は、そのまま。
4. 地面が泥の質感で、水面が薄く光っている。あぜが草の質感。
5. 朝のもやから、夕焼けへ、光が変わっていく。クリアのとき、夕焼けが最も強い。
6. 「もう一度」で、稲も光も、最初に戻る。
7. 重くない(スマホのエミュレーターでも、動きがなめらか)。
