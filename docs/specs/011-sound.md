# 仕様書 011: 効果音・環境音(仕組みだけ作る。音の素材は、開発者が選ぶ)

> 状態: 実装済み(仕組みのみ。音のIDは開発者が入れる)。仕様書007の「次の質感の候補」4番。
> **大事な前提**: 音は、素材(音のファイル)が必要。素材は、CLAUDE.md のルール6により、開発者の確認なしに、勝手に選んで使わない。Claude は、Roblox の音の素材の一覧を、この環境から調べられず、存在する素材のIDも、確かめられない。
> そのため、この仕様書では、**音を鳴らす仕組みだけ**を作る。音のID(素材の番号)は、空のままにしておき、開発者が選んで、Config に入れれば、鳴り始める。IDが空の音は、鳴らさない(エラーにならない)。

## 1. 何のための機能か
環境音(田んぼの虫・水の音)や、効果音(水しぶき、稲刈り機のエンジン、餌を食べる、つかまった、クリア)を、あとから、IDを入れるだけで、足せるようにする。

## 2. 音の一覧(Config の `SoundIds` に、IDを入れる)
| 名前 | いつ鳴るか | 種類 |
|---|---|---|
| Ambient | ゲーム中、ずっと(田んぼの環境音) | くり返し・全体(2D) |
| HarvesterEngine | 稲刈り機が動いている間 | くり返し・稲刈り機について動く(3D) |
| Splash | 潜る・浮上するとき | 1回・全体(2D。自分の端末で、自分のザリガニの音を鳴らすため) |
| Eat | 餌を食べたとき(仕様書012) | 1回・全体(2D) |
| Caught | つかまったとき | 1回・全体(2D) |
| Clear | クリアしたとき | 1回・全体(2D) |
- 初期値は、すべて空の文字(`""`)。空なら、その音は、作らない・鳴らさない。
- 音量は、種類ごとに Config(`SoundVolumes`)で決める。

## 3. 仕組み
- **ID の形**: `rbxassetid://数字` の形だけ、受けつける。ほかの形(外部のURLなど)は、警告を出して、無視する(安全のため)。
- **クライアント(`SoundController`)**: Ambient、Splash、Eat、Caught、Clear を、各自の端末で鳴らす。
  - Ambient: ラウンド中(Playing)に、くり返し再生。Caught・Clear のときは、小さくする(または止める)。「もう一度」で、また鳴らす。
  - Caught・Clear: RoundState が、その状態に変わったとき、1回だけ。
  - Splash: ローカルのキャラクターの Attribute `Hidden` の値が、**実際に変わったとき**(潜る・浮上)に、1回。(生まれ直したときは、最初の値を、鳴らさずに覚えるだけ。)
  - Eat: 仕様書012の ScoreState で、餌を食べたことが分かったとき、1回。(仕様書012で、つなぐ。)
  - Sound は、`SoundService` の下に、1つずつ作り、使い回す(毎回、新しく作らない)。
- **サーバー(稲刈り機)**: HarvesterEngine は、稲刈り機のモデルの中に、Sound(3D、距離で小さくなる `RollOffMaxDistance`)として作り、動いている間だけ、再生する(Sweep が、粒子と同じ形で、切り替える)。IDが空なら、作らない。
- **新しい RemoteEvent は、足さない**(Eat だけ、仕様書012の通信を使う)。

## 4. 数値(Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| SoundIds | すべて空 | 音のID(`rbxassetid://数字`) |
| SoundVolumes | 種類ごとの音量(0〜1) | 音量 |
| SoundHarvesterRollOffMaxDistance | 120 | 稲刈り機の音が届く距離 |
| SoundAmbientDuckVolume | 小さな値 | Caught・Clear のときの、環境音の音量 |

## 5. 開発者がやること(音を鳴らすまで)
1. Roblox のクリエイターストア(Creator Store)の「オーディオ」で、使ってよい音(無料のもの、または、自分で作ったもの)を探し、IDをコピーする。
2. `Config.luau` の `SoundIds` に、`rbxassetid://数字` の形で、貼る。
3. `assets/CREDITS.md` に、音の名前・ID・出どころ・使用条件を、記録する。
4. Studioで、鳴るか確かめる。うるさければ、`SoundVolumes` を下げる。
(詳しくは、`docs/design/sound.md`。)

## 6. 作らないこと
- 音の素材の選択・ID の入力(開発者の仕事)
- 音楽(BGM。環境音で足りるため、必要なら、あとで足す)
- 農家さんの足音、ザリガニの足音

## 7. 確認方法(Studioで遊んで確かめること)
1. IDが空のままでも、エラーや警告が出ない(音は鳴らない)。
2. `SoundIds.Ambient` に、ID を入れると、ゲーム中、その音が、くり返し鳴る。
3. `HarvesterEngine` を入れると、稲刈り機が近いほど大きく聞こえる。動いていない・消えたら止まる。
4. `Splash`、`Caught`、`Clear` が、それぞれのタイミングで、1回ずつ鳴る。
5. 外部のURLなど、`rbxassetid://` 以外の値を入れると、警告が出て、鳴らさない。
