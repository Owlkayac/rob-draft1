# 仕様書 005: ザリガニの見た目

> 状態: 実装済み(開発者が遊んで確認)。開発者の要望: 「逃げるのを、ザリガニの見た目にしたい」。
> 仕様書001の「ザリガニの本物のモデルは作らない(仮の赤い人型)」を、この仕様書で置き換える。

## 1. 何のための機能か
プレイヤーが、人型ではなく、ザリガニの見た目で遊べるようにする。

## 2. 方針(コードで作る。外部の素材は使わない)
- プレイヤーのキャラクターは、これまでどおり、標準の人型(Humanoid)を**動きと当たり判定の土台**に使う。操作とカメラは、そのまま使える。
- 人型の見た目は、**すべて透明にして隠す**(体、顔、髪、帽子、服)。名前の表示と体力バーも消す。
- そのかわりに、**ザリガニの形に組んだ図形(Part)**を、HumanoidRootPart に溶接(WeldConstraint)して、ついて歩かせる。
- ザリガニの図形は、当たり判定・物理の重さを持たない(CanCollide=false、CanQuery=false、CanTouch=false、Massless=true)。

## 3. ザリガニの形(図形で作る・向きは、キャラクターの正面)
| 部分 | 図形 | 数・メモ |
|---|---|---|
| 胴体 | つぶした球(長めの楕円) | 1 |
| しっぽ(腹) | 小さめの箱や円柱を、後ろに3〜4節つなげる | 3〜4。先ほど細く |
| 尾の先(ひれ) | 平たい箱 | 1 |
| 大きなはさみ | 腕(細長い箱、`ClawArm`)+球(`ClawPalm`)+小さな箱(はさみの先、`ClawTip`) | 左右 各1組(2組) |
| お腹の板 | 明るい色の薄い箱(`Belly`)。胴体としっぽの下に敷く | 1 |
| 目 | 小さな黒い球(細い柱の先に) | 左右 2 |
| ひげ | 細長い円柱 | 左右 2 |
| 足 | 細い円柱 | 左右 3〜4本ずつ |
- 形の細部の数字(各部品の大きさ・位置・角度など)は、Config には入れず、`CrayfishModel.luau` の中の定数にまとめてある。
- 色: 全体は赤(`CrayfishColor`)。お腹側や足は、少し明るく(`CrayfishBellyColor`)。目は黒。
- 大きさ: 全長は、おおよそ 4.5 スタッド、幅 3、高さ 1.6。位置は、地面に近く(足が、ゆか上面に近づく高さ)。人型の当たり判定(高さ約5)よりずっと低くなるが、当たり判定は変えない。
- 見た目のモデルは、キャラクターの中の `CrayfishVisual` というフォルダ(Folder)にまとめる。

## 4. 他の機能との関係
- **潜る(仕様書001)**: 潜っている間は、ザリガニの図形が、半透明になる(`DiveTransparency`)。人型の隠した部分は、もともと透明なので、見えるようにならない(濃いほうを使う)。浮上すると、元に戻る。
- **やり直し・生まれ直し**: 生まれ直すたびに、新しいキャラクターに、ザリガニの見た目をつけ直す。服や髪は、あとから読み込まれるので、読み込み後にも、もう一度、隠す。
- 農家さんの捕まえる距離や、捕まったときの動きは、変えない。

## 5. 数値(Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| CrayfishColor | 赤(既存) | 体の色 |
| CrayfishBellyColor | 明るい赤やオレンジ | お腹・足の色 |
| CrayfishEyeColor | 黒 | 目の色 |
| CrayfishBodyLength | 4.5 | 全長の目安 |
| CrayfishBodyHeight | 1.6 | 高さの目安 |
| CrayfishGroundOffset | (土台の中心から、ザリガニの中心までの下向きの距離) | 地面に近づける調整値 |

## 6. 作らないこと
- 歩くアニメーション(足が動く、など)(仕様書010で作った)
- 潜るときの沈むアニメーション(半透明になるだけ)
- 見た目の着せ替え(あとで、ゲームパスにしてもよい)
- 効果音

## 7. 確認方法(Studioで遊んで確かめること)
1. ゲームを始めると、人型は見えず、赤いザリガニが、田んぼにいる。はさみ、目、ひげ、しっぽがある。
2. 歩くと、ザリガニが、正面を向いて進む。地面から浮いたり、めり込んだりしない。
3. 潜ると、ザリガニが半透明になり、浮上すると元に戻る。
4. 「もう一度」で生まれ直しても、同じ見た目で出てくる。
5. 自分の名前や体力バーが、頭の上に出ていない。
