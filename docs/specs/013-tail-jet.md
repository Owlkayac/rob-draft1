# 仕様書 013: 尻尾のジェット(ジェットモード)

> 状態: 実装済み(開発者の確認待ち)。開発者の依頼: 「尻尾を使いジェットモードを追加したい。秒数はいいかんじで」。
> 本物のザリガニは、尻尾をはじいて、水を切って、一気に逃げる。それを、能力(ジェット)にする。

## 1. 何のための機能か
潜って隠れる(仕様書001)のほかに、**動いて逃げる**手段を足す。農家さんに見つかったときの、ぎりぎりの脱出や、稲刈り機のよけ、遠い餌を、すばやく取りにいくために使う。

## 2. ふるまい
- **発動**: パソコンは **Q キー**、スマホは画面の「ジェット」ボタン。押した瞬間に、1回、発動する(押しつづける必要はない)。
- **噴射**: 発動すると、`JetSeconds`(**0.8秒**)のあいだ、**ふだんの `JetSpeedMultiplier`(2.4)倍の速さ**で、まっすぐ進む(進む向きは、発動した瞬間の、動かしている向き。動かしていなければ、ザリガニが向いている向き)。噴射中は、向きを変えられない(まっすぐ噴射)。入力がなくても、進む。壁(あぜ)で止まる。
- **ため直し(クールダウン)**: 噴射が終わってから、`JetCooldownSeconds`(**8秒**)は、使えない。ゲームを始めたとき・やり直したときは、すぐ使える。
- **使えないとき**: 潜っている間、つかまった・クリアしたあと、すでに噴射中、ため直し中。ジェット中は、潜れない(潜る要求は、無視される)。
- **見た目と演出**:
  - 尻尾が、体の下に、ぱっと丸まって(はじいて)、ゆっくり戻る(クライアントのアニメーション)。
  - 尻尾の先の少し後ろ(胴体につけた、見えない小さな部品 `JetNozzle`)から、青白い水の噴射(粒子)が、後ろに出る(噴射中だけ。尻尾が丸まっても、向きは変わらない)。
  - 噴射の瞬間、カメラの視野(FieldOfView)が、少し広がり、すばやく戻る(スピード感。自分の端末だけ)。
  - 画面の下に、「ジェット: じゅんびOK」「ジェット: あと 3.2びょう」を、小さく出す。
- 農家さん・稲刈り機・餌・点数のルールは、変えない(ジェット中も、捕まる・食べられる判定は、いつもどおり)。

## 3. 「いい感じ」の秒数の考え方
| 項目 | 値 | ねらい |
|---|---|---|
| 噴射の長さ | 0.8秒 | 短く、決定的な1発。長いと、操作できない時間が長くなる |
| 速さの倍率 | 2.4倍(約38) | 約30スタッドを進む。農家さん(追跡の速さ15)から、一気に離れられる |
| ため直し | 8秒 | 潜る(3秒+5秒)より、やや長い。つねに使えると、ゲームが簡単すぎる |
- 農家さんの「見つける距離」(30)の外まで、ほぼ1発で、離れられる。稲刈り機(速さ13)は、横にジェットすれば、確実によけられる。
- 遊んでみて、強い・弱いと感じたら、Config の数字だけを変える。

## 4. 実装の方針(サーバーとクライアント)
- **サーバー(CrayfishService)**: ジェットの状態(噴射中か、使えるようになる時刻、タイマーの番号)を、`Player` をキーにした表で持つ(仕様書001の「潜る」と同じ形)。
  - 通信: 新しい RemoteEvent `JetRequest`(クライアント → サーバー。値なし)。サーバーは、送信者の状態、値がないこと、受け付け間隔(`JetRequestMinInterval`)、使える条件(生きている・潜っていない・噴射中でない・ため直しが終わっている・Humanoid が生きている)を、すべて確認してから、発動する。
  - 発動: `Humanoid.WalkSpeed` を、`CrayfishWalkSpeed × JetSpeedMultiplier` にする。キャラクターに、Attribute `Jetting = true` をつける。噴射の粒子(`JetEmitter`)の `Enabled` を true にする。
  - 終了(`JetSeconds` 後。タイマーの番号で、古いタイマーを無効にする): `WalkSpeed` を戻し、`Jetting = false`、粒子を止める。使えるようになる時刻を、Attribute `JetReadyTime`(サーバー時刻 `workspace:GetServerTimeNow()` で、いつ使えるか)に、設定する。
  - 噴射中に、つかまった・クリア・死亡・生まれ直しで、噴射を終わらせる(`WalkSpeed`、Attribute、粒子を、元に戻す)。ため直しは、生まれ直しで、リセットする。
- **クライアント(`JetController`、新しい部品)**:
  - 入力: `ContextActionService` で、Q キーと、スマホの画面ボタン(「ジェット」)を登録。押したら `JetRequest` を送る(ため直し中・噴射中は、送らなくてよい。ただし、サーバーが、最終的に判断する)。
  - 噴射中(Attribute `Jetting` が true の間): 発動の瞬間の向き(いまの動かしている向き。なければ、ザリガニが向いている向き)に、`Humanoid:Move(向き, false)` を、毎フレーム、ふだんの操作の入力より、あとの順序(`Enum.RenderPriority.Input.Value + 1`)で呼び、まっすぐ進ませる。終わったら、外す。
  - 視野: ローカルのカメラの `FieldOfView` を、`JetFovAdd` だけ広げ(`JetFovInSeconds`)、噴射が終わったら、戻す(`JetFovOutSeconds`)。TweenService を使う。
  - 画面の表示: 小さな ScreenGui を、自分で作り、`JetReadyTime` と `workspace:GetServerTimeNow()` から、残り時間を計算して、「ジェット: じゅんびOK」か「ジェット: あと N.N びょう」を出す(0.1秒ごとの更新で十分)。
- **尻尾の動き(`CrayfishModel` と `CrayfishAnimator`)**: 尻尾(節と、尾の先のひれ)を、1つの Motor6D(名前 `Tail`。尻尾の付け根が、回転の中心)で、動かせるようにする(尻尾の節とひれは、その Motor6D の部品に、WeldConstraint でつなぐ)。クライアントの `CrayfishAnimator` が、`Jetting` が true になった瞬間から、尻尾を、体の下に丸める(`CrayfishTailCurlDeg`、`CrayfishTailCurlInSeconds` で素早く)、少し保ち、ゆっくり戻す(`CrayfishTailReleaseSeconds`)。ふだんは、歩くと、ほんの少し左右にゆれる(任意)。潜っている間は、止める。
- **音**: 音の仕組み(仕様書011)に、`Jet` を足す(IDは空)。噴射の始まりに、1回、鳴る。

## 5. 数値(Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| JetSeconds | 0.8 | 噴射の長さ |
| JetSpeedMultiplier | 2.4 | 噴射中の速さの倍率 |
| JetCooldownSeconds | 8 | ため直し |
| JetRequestMinInterval | 0.3 | 発動の要求の、受け付け間隔の最小(最後に「発動した」時刻と比べる) |
| JetWaitSeconds | 10 | JetController が RemoteEvent を待つ最大の秒数 |
| JetGuiUpdateSeconds | 0.1 | 画面の下の表示の更新間隔(0 にしない) |
| JetFovAdd / JetFovInSeconds / JetFovOutSeconds | 12 / 0.12 / 0.4 | 視野の広がり |
| CrayfishTailCurlDeg / ...InSeconds / ...HoldSeconds / ...ReleaseSeconds | 45 / 0.1 / 0.3 / 0.35 | 尻尾の動き(In + Hold + Release の合計は、JetSeconds 以下) |
| Jet...(粒子の数・大きさ・寿命・速さ・色) | 控えめ | 噴射の粒子 |

## 6. 作らないこと
- ジェット中の、向きの変更(まっすぐのみ)
- 後ろ向きの噴射(本物のザリガニは後ろに進むが、遊びやすさのため、前に進む)
- ジェット専用の、ゲームパス・課金
- 農家さん・稲刈り機の、ジェットに対する反応

## 7. 確認方法(Studioで遊んで確かめること)
1. Q キー(スマホは「ジェット」ボタン)で、0.8秒のあいだ、一気に進む。尻尾が丸まり、後ろに、水の噴射が出る。視野が、少し広がる。
2. 噴射したあと、8秒は、もう一度、使えない。画面の下の表示が、「あと N.N びょう」から、「じゅんびOK」に変わる。
3. 動かしていなくても、噴射できる(向いている向きに進む)。壁で止まる。
4. 潜っている間は、ジェットできない。噴射中は、潜れない。
5. つかまる・クリアすると、噴射が止まる。「もう一度」で、すぐ使える状態に戻る。
6. 農家さんから、ジェットで逃げられる。稲刈り機を、横に噴射して、よけられる。
7. 「出力」に、エラーが出ない。
