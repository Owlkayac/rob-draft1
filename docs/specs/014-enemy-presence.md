# 仕様書 014: 天敵の動きのランダム性と、臨場感

> 状態: 実装済み(開発者の確認待ち)。開発者の依頼: 「もう少し天敵の動きにランダム性を出してみて。臨場感をさらに強めて」。
> 方針: 「予測できない怖さ」(ランダム性)と、「巨人が迫ってくる実感」(演出)の2つを足す。ただし、**理不尽にはしない**(最低限の公平さを、数字で守る)。外部の素材は使わない。

## 1. ランダム性(サーバー。農家さんと稲刈り機)
乱数は、`Random.new()`(毎回違う)で作る。`Config.EnemyRandomSeed` が 0 以外なら、その値で固定する(デバッグ用)。

### 1-1. 農家さんの見回り
- **次の行き先をランダムに**: 固定の順番ではなく、次のどちらかを選ぶ。
  - 確率 `FarmerRoamPointChance`(0.5)で、**田んぼの中のランダムな点**(壁から `FarmerRoamWallMargin`(15)以上はなす)。
  - そうでなければ、見回り地点(5か所)のうち、**直前に行った地点以外**から、ランダムに1つ。
- **立ち止まる**: 行き先に着いたとき、確率 `FarmerPauseChance`(0.4)で、`FarmerPauseSecondsMin`〜`Max`(1.0〜3.0秒)立ち止まって、ゆっくり向きを変える(きょろきょろする)。
- **速さのゆらぎ**: 見回りの歩く速さを、1回の移動ごとに、±`FarmerWalkSpeedJitter`(0.12 = 12%)でゆらす。
- **「勘」**: 見回り中、`FarmerHunchIntervalMin`〜`Max`(8〜14秒)ごとに、確率 `FarmerHunchChance`(0.5)で、いちばん近い、遊んでいるプレイヤーの**だいたいの位置**(`FarmerHunchErrorRadius`(22)のずれ)を、次の行き先にする。ザリガニを見つけたことにはならない(発見の判定は、これまでどおり)。「なんとなく、こっちに来る」怖さを出す。

### 1-2. 農家さんの追跡
- **気づく間(反応の遅れ)**: 見つけてから、すぐには走らない。次の「3. 気づく演出」の、`FarmerNoticeSecondsMin`〜`Max`(0.4〜0.9秒)だけ、立ち止まって、ザリガニのほうを向く。
- **ダッシュ**: 追跡中、ランダムな間隔(`FarmerBurstIntervalMin`〜`Max`: 4〜9秒)で、短く(`FarmerBurstSeconds`: 1.0秒)、速さが `FarmerBurstMultiplier`(1.12)倍になる。
- **つまずき**: 追跡中、ランダムな間隔(`FarmerStumbleIntervalMin`〜`Max`: 6〜14秒)で、`FarmerStumbleSeconds`(0.35秒)だけ、足が止まる。
- **速さの上限(公平さ)**: 追跡の速さは、ザリガニの歩く速さ(`CrayfishWalkSpeed`)の `FarmerChaseMaxSpeedRatio`(1.05)倍を、超えない。(ダッシュしても、ジェット・潜るで、逃げられる範囲。)
- **見失うまでの時間**: `FarmerLoseSightSecondsMin`〜`Max`(3〜6秒)の、ランダム。

### 1-3. 農家さんの「探す」
- 探す時間を、`FarmerSearchSecondsMin`〜`Max`(2〜5秒)の、ランダムにする。
- 探すあいだ、最後に見えた位置の近く(半径 `FarmerSearchRoamRadius`(18))を、1〜2か所、ランダムに、歩く。そのあと、見回りに戻る。

### 1-4. 稲刈り機
- **入る側がランダム**: 毎回、田んぼの**西**か**東**のどちらかから入る(東から入るときは、経路を左右反転する。刈る範囲・順番・長さは、同じ)。
- **速さのゆらぎ**: 線ごとに、速さを、±`HarvesterSpeedJitter`(0.08)でゆらす。

### 1-5. 公平さの保証
- 出現してから `FarmerStartGraceSeconds`(3秒)は、プレイヤーを見つけない(いきなり捕まらない)。
- 気づいてから走るまで、最低 `FarmerNoticeSecondsMin`(0.4秒)かかる。
- 追跡の速さの上限(上のとおり)。
- 乱数による、動きの変化は、**ゲームの勝ち負けを、運だけで決めない**範囲にとどめる。

## 2. 気づく演出(農家さん)
- **新しい行動 `Notice`(気づく)**: 見回り・探すの最中に、プレイヤーを発見したら、`Notice` に入る(`FarmerNoticeSecondsMin`〜`Max` のランダムな間、立ち止まり、ザリガニのほうを向く)。その間に、ザリガニが、潜った・見えなくなったなら「探す」へ。そうでなければ「追跡」へ。
- **頭の上の表示**(BillboardGui。農家さんの頭に、サーバーがつける。文字は、画面に重なって、遠くからも見える大きさ。常に手前に表示):
  - `Notice`・追跡: 赤い「!」
  - 探す: 黄色い「?」
  - 見回り: 出さない
- **状態の公開**: 農家さんのモデルに、Attribute `EnemyState`(文字列: `Patrol` / `Notice` / `Chase` / `Search`)をつける。クライアントの演出が使う。
- **音の場所だけ用意**(IDは空): `Config.SoundIds` に、`FarmerNoticed`(気づいたとき)、`FarmerStep`(足音)、`Heartbeat`(心臓の音)を足す(仕様書011の仕組み)。

## 3. 巨人の歩きと、近づく怖さ(クライアント)
新しい部品 `EnemyPresenceController`(クライアント)。見えているすべての天敵のうち、`EnemyState` を持つもの(農家さん)を対象にする。

- **巨人の歩き**: 農家さんは、人型(R15)の関節(Motor6D)を持つ。その `Transform` を、速さに合わせて、動かす(クライアントだけ。ザリガニの足の動き(仕様書010)と同じ方式)。
  - 歩く・走る: 足が交互に前後にふれ、腕が、足と逆にふれる。体が、少し上下する。
  - 立ち止まる: 動きを止める(息づかい程度に、ゆっくり)。
  - `Notice`: 腕を、少し持ち上げる。
  - `Search`: 首を、左右にふる(きょろきょろ)。
  - 関節が見つからない(簡易モデル)ときは、何もしない(エラーにならない)。
- **足音(ズシン)**: 足が地面につく瞬間(歩きの周期の区切り)ごとに、次を行う。
  - **カメラの揺れ**: ローカルのキャラクターの `Humanoid.CameraOffset` を、農家さんとの近さに応じて、上下に小さくはねさせ、すぐ戻す(`FarmerShakeMaxDistance`(60)以内で、近いほど強い。最大 `FarmerShakeMaxOffset`(0.35))。
  - **足音**: `SoundIds.FarmerStep` があれば、農家さんの `HumanoidRootPart` の下(足元の近く)に Sound を置いて、3Dで、鳴らす。
- **近づく緊張**: 農家さんが、`Notice` か `Chase` で、近い(`FarmerThreatMaxDistance`(45)以内)ほど、画面を、少し赤く・暗く・彩度を上げる(新しい `ColorCorrectionEffect` "FieldThreatColorCorrection"。既存の光の演出とは、別のものを足して、重ねる)。離れる・見失う・探すに戻ると、なめらかに、元に戻る。
- **心臓の音**: `SoundIds.Heartbeat` があれば、追跡・気づくのときだけ、くり返し再生し、近いほど音量を上げる(IDが空なら何もしない)。

## 4. 数値(Config.luau にまとめる)
上の本文の、`Farmer...`、`Harvester...`、`EnemyRandomSeed` の数字を、すべて Config にまとめる。割り算に使うもの(間隔、時間)は、0 にしない。

## 5. 作らないこと
- 農家さんが、複数になること
- 農家さん以外(稲刈り機)の、歩くアニメーション
- 効果音の素材のID(開発者が選ぶ。仕様書011)
- 乱数による、速さの上限を超えるダッシュ
- ザリガニ(プレイヤー)の動きの、ランダム化

## 6. 確認方法(Studioで遊んで確かめること)
1. 農家さんが、毎回、違う道を歩く。ときどき、立ち止まって、きょろきょろする。ときどき、こちらに向かってくる(勘)。
2. 見つかると、農家さんが、立ち止まり、こちらを向いて、頭の上に「!」が出る(約0.5秒)。そのあと、追いかけてくる。
3. 追跡中に、ときどき、短く速くなる。ときどき、つまずく。それでも、ジェットや潜るで、逃げられる。
4. 見失うと、頭の上に「?」が出て、近くをうろうろ探し、見回りに戻る。
5. 農家さんの足・腕が、歩きに合わせて動く。足が地面につくたびに、画面が、ズシンと揺れる(近いほど強い)。
6. 追いかけられて近づくと、画面が、少し赤く・暗くなる。離れると、戻る。
7. 稲刈り機が、毎回、西か東の、ランダムな側から入る。
8. 「出力」に、エラーが出ない。重くない。
