# 仕様書 009: 粒子の演出(刈りくず、土ぼこり、水しぶき)

> 状態: 実装済み(開発者の確認待ち)。仕様書007の「次の質感の候補」2番。
> 方針: Roblox に最初から入っている **ParticleEmitter(粒子)** だけを使う。粒子の画像は、Roblox の標準(既定)のままにする(外部の画像は、使わない)。粒子は、各自の端末で動くので、サーバーの負担は小さい。

## 1. 何のための機能か
稲を刈った感じ、機械が動く感じ、ザリガニが水に潜る感じを、粒子で強める。

## 2. 演出
### 2-1. 稲刈り機の刈りくず(サーバーで、ParticleEmitter をモデルにつける)
- 刈り取りの刃のところから、緑と黄金色の細かいくずが、前と上に、飛び散る。
- 動いている間だけ出す(入るのを待っている間や、消える間は、出さない)。
- 色: 緑から黄金色へ(ColorSequence)。大きさ: 小さく(0.3〜0.5)。寿命: 0.6〜1.0秒。重力で落ちる(Acceleration)。

### 2-2. 稲刈り機の土ぼこり
- 後ろの車輪のあたりから、薄い茶色の、ふんわりした粒子を、少しだけ出す。
- 動いている間だけ。数は少なめ(重くならない範囲)。

### 2-3. ザリガニが潜る・浮上するときの水しぶき
- 潜る瞬間と、浮上する瞬間に、ザリガニのまわりから、青白い水しぶきが、短く、飛ぶ。
- 実装: ザリガニの見た目の胴体に、ParticleEmitter をつけておき(`Enabled=false`)、潜る・浮上のときに、サーバーが、`Enabled=true` にして、`Config.SplashBurstSeconds`(0.25秒)後に、`false` に戻す。(サーバーで `Emit()` を呼んでも、他の端末には見えないため。)
- 潜っている間に、小さな泡が、ときどき出る(任意。重くなければ)。

## 3. 数値(Config.luau にまとめる)
粒子の、数・大きさ・寿命・速さ・色は、Config にまとめる(`Harvester...Chaff...`、`Harvester...Dust...`、`Splash...` のように、まとまりが分かる名前)。`SplashBurstSeconds = 0.25`。

## 4. 作らないこと
- 稲の1本ずつから、飛び散る演出(稲刈り機の刃から出す、1つの発生源だけ)
- 農家さんの足跡・足音
- 雨、雪、天気
- 外部の画像を、粒子に使うこと

## 5. 注意
- 粒子の画像(Texture)は、設定せず、Roblox の既定のままにする。これは、Roblox に入っているもので、外部の素材ではない。docs/CREDITS には、その旨を書く(assets/CREDITS.md)。
- 粒子は、`Enabled` を切り替えるだけ。毎フレーム、新しく作らない。

## 6. 確認方法(Studioで遊んで確かめること)
1. 稲刈り機が動くと、刃から、緑や金色のくずが飛び散る。止まる・消えると、出なくなる。
2. 後ろに、うっすら土ぼこりが出る。
3. 潜るとき、浮上するとき、一瞬、水しぶきが飛ぶ。
4. 重くない(粒子が出すぎていない)。
