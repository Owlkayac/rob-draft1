# 仕様書 001: ザリガニの操作(移動と、泥に潜る)

> 状態: 実装済み(開発者が遊んで確認)。数字は仮の初期値で、遊びながら調整する。

## 1. 何のための機能か
プレイヤーがザリガニになって田んぼを動き回り、危なくなったら泥に潜って隠れられるようにする。ゲームの基本になる操作。

## 2. プレイヤーの操作と、その結果
1. 移動: パソコンは WASD キー、スマホは左の画面上のスティックで動く(Roblox標準の操作をそのまま使う)。
2. 泥に潜る: 画面の「潜る」ボタンを押している間(パソコンは **E キー**)、泥に潜る。
   - 潜っている間は動けない。
   - 潜っている間は、天敵に見つからない。
   - 潜れる時間には上限があり(スタミナ)、使い切ると強制的に浮上する。
   - 浮上した後は、少しの間(クールダウン)は潜れない。
3. 潜っている間は、ザリガニを半透明にして、泥に沈んで見えるようにする。

## 3. 数値(仮。Config.luau にまとめる)
| 名前 | 初期値 | 意味 |
|---|---|---|
| CrayfishWalkSpeed | 16 | 歩く速さ |
| DiveMaxSeconds | 3 | 連続で潜れる最大の時間 |
| DiveCooldownSeconds | 5 | 浮上してから、次に潜れるまでの時間 |
| DiveRequestMinInterval | 0.2 | 潜る操作の受け付け間隔の最小値(連打対策) |

## 4. サーバーで判定すること
- 「潜っているか」の状態は、サーバーが持つ(Player をキーにした表)。
- クライアント(プレイヤーの端末)は「潜りたい/やめたい」と**お願いするだけ**。
  - 通信の名前: `DiveRequest`(RemoteEvent)。値は true(潜る) / false(やめる) の真偽値のみ。
  - サーバーは、値の型、受け付け間隔、スタミナ、クールダウン、生存中かを確認してから、状態を変える。
- 歩く速さの設定もサーバー側で行う。

## 5. 保存するデータ
なし(最初の版では、記録を保存しない)。

## 6. 作らないこと
- ザリガニの本物のモデル(最初は、赤い箱や丸を組み合わせた簡易モデルで代用する)(仕様書005で作った)
- 歩く・潜るのアニメーション
- 効果音
- ジャンプ

## 7. 確認方法(Studioで遊んで確かめること)
1. 動き回れる(パソコンとスマホのエミュレーターの両方)。
2. 潜るボタンで潜れて、見た目が半透明になる。
3. 3秒たつと、強制的に浮上する。
4. 浮上してから5秒は潜れない。
5. 潜るボタンを連打しても、不具合が起きない。
