# ゲームの企画書

> **状態: 方向は確定(開発者が決定)/ 細部は案(確認待ち)**
> 開発者が決めたこと: 「日本の田んぼで、プレイヤーがザリガニになって逃げて生き延びる」。
> それ以外は、Claudeが下書きした案です。違うところは直してください。

## 1. 一行コンセプト
日本の田んぼで、ザリガニになって天敵から逃げ、稲が育ちきる(稲刈りの日)まで生き延びるサバイバルゲーム。

## 2. 遊ぶ人
- 想定する年齢層(案): 小学生〜中学生。追いかけっこやサバイバルが好きな人。
- どんなときに遊ぶか(案): すきま時間にスマホで。1回5分前後で区切りがつくようにする。

## 3. 30秒のループ(案)
稲や泥の中を動く → 天敵に見つからないよう隠れる → 近づいてきたら逃げる → 逃げ切る → 餌を食べて点数が増える

**1回の流れ(案)**
- 田植えの直後から始まり、稲が育って稲刈りの日になるまでが1回(約5分)。
- 稲が育つほど背が高くなり、隠れやすくなる。
- 終盤は稲刈り機が動き出し、田んぼ全体が危なくなる。
- 稲刈りの日まで生き延びればクリア。

## 4. SNSで映える一瞬
天敵の影が迫る中、稲の間をすり抜けて、ぎりぎりで泥に潜って逃げ切る場面。
(15秒の縦動画で見せる、いちばんの見せ場にする)

## 5. 最初のバージョンに入れるもの(3つ・案)
1. ザリガニを操作して、田んぼの中を動ける(歩く、泥に潜る)。
2. 天敵が1種類だけ(人間の農家さん)現れて追いかけてくる。捕まるとやり直し。
3. 稲が育つ時間の流れ(田植え→稲刈り)があり、最後まで生き延びるとクリアになる。

## 6. 最初は入れないもの(案)
- チャット機能(なくても遊べる設計にするため)
- 複数人で同じ田んぼに入ること(将来の更新で対応。最初は一人用)
- プレイヤー同士の対戦
- 複数種類の天敵
- ザリガニの見た目の着せ替え
- 季節イベント(最初の版を出して反応を見てから作る)

## 7. 収益化(案)
- 最初のバージョンは、課金なしで出す。
- 反応が見えてから、ゲームパス(買い切り)を足す。案: ザリガニの色や模様の変更。有利になる課金にはしない。
- 初日の体験を壊さない。

## 8. 競合と違うところ
- 参考にする人気作: 逃げる・生き延びる系のサバイバルゲーム全般。サバイバルは、いま伸びているジャンル。
- 違い(案): 日本の田んぼが舞台で、プレイヤーはザリガニ。稲の成長が、そのまま制限時間と隠れ場所の変化になる。

## 9. 決めたこと・決めないこと
- 決めたこと: 日本の田んぼが舞台。プレイヤーはザリガニ。逃げて生き延びる。最初の天敵は人間(農家さん)。サギは後で追加する(理由は docs/decisions/001-enemy.md)。最初は一人用で、将来は複数人で遊べるようにする(docs/decisions/002-solo-first.md)。
- 案のまま確認が必要: 1回の長さ、課金の内容。
- まだ決めないこと: ゲームの名前、見た目の雰囲気、季節イベント。
