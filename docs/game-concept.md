# ゲームの企画書

> **状態: 案(開発者の確認待ち)**
> 以下はClaudeが下書きした案です。違うところは直してください。確認が済んだら、冒頭の「案」を「確定」に変え、CLAUDE.md の「未定」も更新します。

## 1. 一行コンセプト
日本の田んぼで米を育てて売る、ほのぼの育成ゲーム。(案)

## 2. 遊ぶ人
- 想定する年齢層: 小学生〜中学生が中心。育てる・集める系が好きな人。
- どんなときに遊ぶか: すきま時間にスマホで。1回5〜10分で区切りがつくようにする。

## 3. 30秒のループ
苗を植える → 少し待つ → 黄金色に実る → 収穫する → 売ってお金が増える

## 4. SNSで映える一瞬
黄金色に実った田んぼを一気に収穫して、米俵が山積みになる場面。
(15秒の縦動画で見せる、いちばんの見せ場にする)

## 5. 最初のバージョンに入れるもの(3つ)
1. 田んぼに苗を植え、時間で育ち、収穫できる。
2. 収穫した米を売って、お金が増える。
3. お金で、田んぼを広げたり、新しい品種を買ったりできる。

## 6. 最初は入れないもの
- チャット機能(なくても遊べる設計にするため)
- プレイヤー同士の取引
- 他のプレイヤーの田んぼへの妨害
- アバターの服や、ペット
- 季節イベント(最初の版を出して反応を見てから作る)

## 7. 収益化
- 最初のバージョンは、課金なしで出す。
- 反応が見えてから、ゲームパス(買い切り)を1〜2個だけ足す。案: 自動で収穫してくれる機能。
- 初日の体験を壊さない。お金を払わないと進めない作りにはしない。

## 8. 競合と違うところ
- 参考にする人気作: 植物を育てて売る育成系のゲーム全般。
- 違い: 日本の稲作が題材。田植えから稲刈り、精米までの流れと、季節ごとのイベント(田植え、稲刈り、新米祭り)を、後の更新で足していく。

## 9. 決めたこと・決めないこと
- 決めたこと(案): ジャンルは育成。最初は課金なし。チャットなし。
- まだ決めないこと: ゲームの名前、見た目の雰囲気、ゲームパスの内容、季節イベントの時期。
